# Власники ⚠ старту — реєстр (`WARN-1`)

> живе доки: `tools/claude-code/warn_owner.py` фільтрує вивід `env_check` (бриф `kernel/Lens_WARN-1_brief.md`).
> читається коли: на старті з'явився рядок «✗ ⚠ … без власника» чи «власник прострочив» · не читається: на старті (прилад читає сам)

**Правило.** Кожне ⚠ старту — з власником і строком, інакше воно стає шумом, на який перестають діяти (EquipLens S41: самері виросло до 132 КБ під ⚠, яке висіло щостарту). Власник — одне з трьох:
- `ID` пункту черги репо чи ядра — прилад звіряє, що пункт відкритий;
- рішення Konst — його словами з датою (напр., «аудит — не запускати»);
- ⓘ «чому не треба» — свідомо прийняте; рядок старту стає ⓘ.

Строк «до» — не далі ніж 30 днів від «з»: тиша з кінцем (rootly.com «Alert management best practices», 22.11.2026). Строк минув — ✗ на старті: переглянь рядок (продовж із новою причиною, закрий пункт або прибери ⚠ у приладі). Ключ — регулярний вираз Python по тексту ⚠, без чисел (числа міняються щостарту). Рядок «свого годинника» («збірка йде», «самері відстає», «треба pull») прилад не судить: ліки — цієї ж години.

**Як перевірити:** `python3 tools/claude-code/warn_owner.py selftest`; зуб — `ENV_INJECT=1 bash tools/env_check.sh` у будь-якому репо → «--inject ЗЛОВИВ».
