## Перевірка, що все на місці (агент, перша сесія на новому акаунті)

- профіль (лише 1-б): `bash tools/claude-code/hooks/lens-hooks.sh profile-test` → 2 × ✓, а в контексті сесії є блок «ПРОФІЛЬ KONST (з репо ядра…)»;

- `bash tools/env_check.sh` у репо проєкту → рядок `env:` — `github=200` · `cloudflare` · `CLOUDFLARE_API_TOKEN=так` · `GH_TOKEN=так`;
- гачки живі: `ls ~/.claude/settings.json` і `bash <ядро>/tools/claude-code/hooks/handoff-remind.sh selftest`;
- конектори: виклик `gh_list` («Lens GitHub») відповідає.

## Чому не вставляти профіль у перше повідомлення щоразу (питання Konst 18.10.2026)

Токенів — стільки ж, але: (1) повідомлення можна забути або вставити старий текст; (2) довга розмова стискається — текст першого повідомлення стає переказом, а гачок старту кладе профіль заново і після стиснення; (3) профіль у репо — одна копія, правиться комітом. Що вантажить сесію Claude Code на старті: системна інструкція Claude Code → профіль з налаштувань акаунта (якщо є) → `CLAUDE.md` репо сесії → контекст гачків старту (`env_check`, профіль 1-б) → твоє перше повідомлення.

## Повернення на свій акаунт (і назад) — швидко

Усе в репо, тож повернення — просто нова сесія на своєму акаунті зі стартовим повідомленням з самері (§6). Різниця лише одна: **свій акаунт** — профіль у полі налаштувань, `LENS_PROFILE` **не** ставити; **спільний** — поле не чіпати, `LENS_PROFILE=1` у середовищі. Середовища обох акаунтів живуть паралельно, їх не треба видаляти — наступний переїзд займе хвилину.

## Профіль лише в репо і на своєму акаунті? (питання Konst 18.10.2026 — на перевірку, не рішення)

- **Для Claude Code — краще:** одна копія в репо, без ручного копіювання в налаштування (зникає розбіжність «PROFILE.md ⟂ поле акаунта»), переїзд — одна змінна.
- **Але поле профілю живить і чати claude.ai та Project «Lens PWA»** — гачків там нема, а інструкцію Project свідомо стиснули, бо «профіль акаунта вантажиться в кожен чат сам» (`kernel/Lens_PROJECT_instruction.md`, `tools/ADAPT.md` §4-б). Прибрати профіль з поля = Project втратить мову, цикл і звіт.
- **Слабкі місця гачка:** профіль є лише там, де працюють гачки ядра (setup script v3 + клон ядра); вага контексту гачка проти профілю акаунта — не перевірено; повтор після стиснення — виправлено в Claude Code 04.2026 (claudeissues 28305), перевіряти на своїй версії.
- **Порядок:** спершу пожити кілька сесій на резервному акаунті з `LENS_PROFILE=1` (маркер, звіт, цикл — як завжди?) → тоді на своєму: поле → коротка заглушка «профіль — у репо `tools/claude-code/PROFILE.md`; у Project прочитай його конектором на старті» + правка інструкції Project тим самим ходом + `LENS_PROFILE=1` у середовищі. Повний профіль у полі **разом** з `LENS_PROFILE=1` — ні (двічі).
- **Інший штатний шлях (не перевірено в хмарі):** setup script копіює `PROFILE.md` у `~/.claude/CLAUDE.md` — пам'ять користувача Claude Code вантажиться щосесії (code.claude.com/docs/en/memory); зараз цього файла в контейнері нема.
