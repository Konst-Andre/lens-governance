# Скіл для claude.ai — рецепт (як зробити, завантажити, оновити, перевірити)

> живе доки: люди Konst працюють у claude.ai чатах і їм потрібні сталі знання (брендбук, шаблон, процедура).
> Народився в AE S158 (27.11.2026, скіл «Брендбук АНЦ» для Олі — `AE-Simulator:docs/brand/skill/`, В-418);
> перевірено живим запитом на акаунті Олі. Читати, коли хтось «щоразу кидає той самий файл у чат» або просить скіл.

## Коли скіл, а не Project / профіль
- **Скіл** діє в **будь-якому** чаті акаунта; у контексті завжди лише `name` + `description` (≈100 токенів),
  тіло SKILL.md — коли запит збігся з описом, файли — коли агент їх відкрив. Чарівне слово не потрібне;
  слово з опису в запиті («за брендбуком АНЦ») — найнадійніше.
- **Project** — лише всередині проджекту (люди часто працюють у чатах). **Профіль** — лише текст і йде в усі
  сесії акаунта, **зокрема Claude Code** (спільний акаунт → шум). Тест AE: скіл спрацював без рядка профілю.
- Скіли акаунта **синхронізуються в Claude Code** (видно як `anthropic-skills:<name>`), однобічно.

## Будова (Anthropic «How to create custom skills», 27.11.2026)
- ZIP: **верхній рівень — тека `<name>/`** з `SKILL.md`; `name` — `[a-z0-9-]`, ≤ 64, ≡ імені теки.
- `description` — що й коли, словами запиту людини; офіційно ≤ 1024, стороннє джерело — 200 на claude.ai →
  тримаємо ≤ 200. SKILL.md < 500 рядків; довге — `references/*.md`, файли — `assets/`, код — `scripts/`
  (шлях — `${CLAUDE_SKILL_DIR}`; нема змінної — `find / -path '*<name>/SKILL.md'` першою дією).
- Код у скілі працює лише з увімкненим «Code execution / Create and edit files». Механіку файлів (.pptx, .docx,
  .xlsx) дають вбудовані скіли Anthropic — свій скіл описує **вигляд і правила**, а не дублює механіку.
- PDF без тексту (криві) агент «читає очима» — переписати текст у `references/`, лого й картинки — окремими файлами.

## Завантаження й оновлення (перевірено з iPhone, 27.11.2026)
- Перше: claude.ai **у браузері** (в iOS-застосунку пункту нема) → Customize → Skills → «+» → Upload → **.zip**.
  Скіл з'являється як **плагін** «<Name>» (Плагіни → «Додано»), у чаті — `/<name>`.
- Нова версія: Плагіни → «<Name>» → «⋯» → «Завантажити нову версію» → лише **`.skill`** або `SKILL.md`
  (`.skill` = той самий ZIP з іншим розширенням); старі версії лишаються в історії.
- Агент **не може** завантажити скіл у claude.ai сам — лише людина; агент віддає файл (SendUserFile).

## Перевірка
1. Збирач з перевірками і зубами — зразок `AE-Simulator:tools/brand/skill_build_v1.py` (ім'я ≡ тека, опис ≤ 200,
   кожен згаданий файл існує — і короткі імена в таблицях, скрипти запускаються, ZIP з текою; `--inject=1·2·3` → ✗).
2. Живий тест: новий чат, запит **без** назви скіла → у «Підсумку» кроку має бути «Завантажено навичку <name>».
3. Результат — очима за чек-листом скіла; «Помилка» кроку агента — відкрити й прочитати (у AE це був `which`
   неіснуючих програм пісочниці, не вада скіла).
