## Проба Haiku 5.5 №1 — чернетка журналу самері (з еталоном)

Чому саме вона: Anthropic радить Haiku для підсумків, а самері тепер — **живий журнал** (профіль v13, `SUM-1`), рядок на кожен хід — масова однотипна робота. І є **еталон**: таблиця §1 самері `QR-Lens:sessions/QR_Lens_session_summary_CC1_ADOPT.md` (≈35 рядків, написав Opus 07.10, кожен рядок звірений з комітом).
- **Вхід Haiku:** лише `git log` сесії CC-1 обох репо (повідомлення комітів + `--stat`), інструкція формату рядка §1 (хід · коміт · суть · перевірка) — без доступу до еталона.
- **Міра** (рахує Opus, не на око): рядків з комітом, якого нема в git log (вигадка) — має бути **0**; ходів еталона, яких Haiku не відобразила (пропуск); факти з неправильними числами чи хешами; «перевірка» без доказу; ціна $ і час — з `claude -p --output-format json`.
- **Вирок:** вигадок 0 і пропусків ≤ 10 % → Haiku пише чернетку журналу, Opus звіряє й комітить; інакше — записати, де ламається, і не використовувати.
- **Запуск:** `claude -p --model haiku --output-format json` з контейнера, рядок у чаті до запуску (модель · effort · навіщо); результат — рядок сюди.
