## Порядок читання на старті сесії

0. `bash tools/env_check.sh`
1. `CLAUDE.md`
2. найновіше самері `docs/summary/` — §0 «ВІДКРИТЕ»
3. `docs/CHERGA.md` — цілком
4. точково: `docs/DECISIONS.md` → `docs/ARCHITECTURE.md` → <довідники>

## Дерево

```
<репо>/
├─ CLAUDE.md          <роль>
├─ <тека сайту>/      <що публікується і ким>
├─ docs/              <документація>
├─ tools/             <гейти, скрипти>
└─ archive/           <історія — не правиться>
```
