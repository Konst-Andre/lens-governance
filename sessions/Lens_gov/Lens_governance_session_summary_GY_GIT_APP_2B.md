## §3 · ПРАВИЛА, ЩО НАРОДИЛИСЬ (повним текстом, `14.29`)

**П-GY1 · Dry-run пушу доводить запис, лише коли є що передати.**
*Тригер:* перевірка запису (П-GX1) у репо, де локальний `HEAD` ≡ `origin/main`.
*Дія:* пушити в dry-run **викидний коміт**: `c=$(git commit-tree HEAD^{tree} -p HEAD -m test); git push --dry-run origin $c:refs/heads/main`;
✓ = рядок `a..b -> main` у виводі. Коміт не потрапляє в жодну гілку.
*Чому:* `git push --dry-run origin HEAD:main` при `HEAD ≡ main` друкує «Everything up-to-date» і **не доходить до авторизації** — G-Y
на старті отримала «✓» у трьох репо, який нічого не доводив.
*Анти-приклад:* G-Y п.0, перший прогін — три «Everything up-to-date».
*Детектор (К2):* рядок «dry-run ✓ <репо>» у мікроскопі без `-> main` у цитованому виводі → ✗. Дім після ухвали — `kernel/Lens_github_push_protocol.md` поруч із П-GX1.
