# wsd — DELTA (running buffer)

**Що це.** Вхідний лоток для нових правил `Work_Standard.md` — те саме, що
`Lens_cookbook_delta_running.md` робить для Cookbook, а `Lens_stagebench_delta_running.md`
для маніфеста стендів.

**Формат запису — обов'язковий:** тригер → дія → чому → анти-приклад → **детектор (К2)**.
Запис без тригера або без детектора **не мерджиться** — доробляється тут.

**Правило.** Буфер — не архів. Лежить довше 2–3 сесій — мерджити як є, не чекати.

> ⚠️ **Колізія паралельних сесій (14.29).** Буфер не має блокування: дві сесії одного дня
> затирають одна одну, і запис зникає **мовчки**. Тому текст правила мусить лежати
> **цілком у самері** тієї сесії, що його породила, а не рядком «записано в буфер».
> Буфер — транспорт, самері — свідок. Два записи з однаковим номером = ознака колізії.
