# StockCheck · NETS register (net → {label, badge, color})

> **Мета:** єдина точка правди для мережевого шару StockCheck — схема запису мережі, **1 реальний
> якір**, синтетична **edge-стаб-матриця** для стрес-тесту бейджа, правила fallback/contrast-floor і
> UI-масштабування net-switcher за кількістю мереж. Feeds порт у поточний білд StockCheck
> (`StockCheck_port_bNN.html`, актуальний — `b16`).

> **Провенанс:** findings §2/§3/§6 + valuesLOCK §4/§8 + island-harness v2 `NETS[]` + memory (net-модель).
> **Дисципліна:** авторитетний список мереж по SKU-зрізу від стейкхолдерів **ще НЕ надано** → будуємо
> на 1 real + синтетиці (wsd 3.6 — стаби чітко позначені, edge > реальні дані для стресу; НЕ вигадувати

## §1. Схема запису мережі

```
net = {
  id:            string,   // стабільний ключ (не міняється при ребренді label)
  label:         string,   // повна назва для UI (switcher-рядок, заголовок)
  short?:        string,   // ≤3-символьний моно-гліф (АНЦ→"АНЦ"); опц.
  svg?:          string,   // векторна бейдж-іконка (пріоритет); опц.
  bg:            "#hex",   // заливка тайла (badge-fill вісь, ⟂ island-tint — findings §3)
  fg:            "#hex",   // колір гліфа/моно
  real:          boolean,  // true = жива мережа; false = синтетичний edge-стаб
  contrastFloor?: boolean  // true = форс безрамкового concentric-underlay (edge-нети, findings §3-⚠️)
}
```

- `bg/fg` — **badge-fill вісь**, повністю незалежна від `island-tint` (findings §3: дві осі не змішувати).
- `contrastFloor` за замовч. **авто** (див. §4-тригер), `true` = ручний форс.

## §2. Fallback-ланцюг вмісту бейджа (як у harness `badgeHTML`)

1. **`svg`** присутній і не форс-моно → векторна іконка (масштаб `badgeScale:1.28`, valuesLOCK §4).
2. інакше **`short`** заданий / label ≤ ~14 симв. → моно-гліф `short` (або авто-ініціали).
3. інакше **авто-моно** — ініціали з label (довга назва → 2 літери), щоб тайл ніколи не переповнявся.

> **Моно-фолбек = авто-запобіжник, не форс** (valuesLOCK §4: `mono:false`). Спрацьовує сам для
> wordmark-only / довгих мереж. Тайл — фіксований 35/R16/inset4; вміст вписується, не навпаки.

## §4. Edge-стаб-матриця (синтетична — стрес бейджа, `real:false`)

> Кожен стаб стресує **ОДИН** вимір. Ці записи — фікстури для harness/QA, **не** для проду з реальними даними.

| id | label | render | bg / fg | стресує | floor? |
|---|---|---|---|---|---|
| `e-short` | АНЦ | mono "АНЦ" | `#c0392b` / `#fff` | 3-символьний моно-фіт | — |
| `e-long` | Аптека Низьких Цін Плюс Подорожник | авто-моно (2 літ.) | `#2660c8` / `#fff` | довга назва → fallback, 0 overflow | — |
| `e-light` | Світла мережа | mono "СМ" | `#f2e08a` / `#5a4a12` | 🔑 **світлий бейдж на світлому склі** | **✅ force** |
| `e-dark` | Нічна | mono "Н" | `#1a2430` / `#cfe0ff` | темний бейдж на темному склі | авто |
| `e-teal` | Тіва | mono "Т" | `#1f9d84` / `#fff` | 🔑 **колізія з accent-162** | авто |

**contrast-floor тригер (авто-правило):**
- Δ(luma(bg), luma(island-bg-під-темою)) < поріг → floor **вмикається** (гарантія читабельності).
- `e-light` на світлій темі + `e-teal` при `tint:accent` = класичні кандидати.
- Реалізація floor = **безрамковий concentric underlay** (findings §3-⚠️/§6), НЕ bordered-plate (той дає подвійну рамку — device v2). **DEFER** до першого реального edge-нета; для якоря `add` не потрібен.

## §5. Net-switcher — UI-масштаб за кількістю мереж (N)

| N | UI-патерн | нота |
|---|---|---|
| **1** (поточний: тільки `add`) | **статичний бейдж**, без chevron/тапу | немає що перемикати — бейдж = чиста айдентика |
| **2–~6** | бейдж = **тапабельний switcher** (chevron), sheet/inline-список | net-switcher з'являється лише при N≥2 |
| **≥~7** (напр. N=10) | switcher = **скрол/пошук-лист** у sheet, не inline-cycle | inline-гортання не масштабується; список із пошуком |

- **Правило:** switcher-афорданс **умовний від N** — не малювати chevron при N=1 (обіцяє дію, якої нема).
- Порт: `renderNetBadge(nets)` гілкується по `nets.length` (1 → static, ≥2 → switcher, ≥7 → searchable).
