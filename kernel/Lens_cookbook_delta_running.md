# Lens Cookbook — DELTA (running buffer)

**Що це.** Вхідний лоток для нових записів `Lens_iOS_cookbook.md`.
Знахідка фіксується тут одразу (щоб не загубилась), але **не роздуває** Cookbook,
який уже 2000+ рядків і стоїть у черзі на розпил по розділах.

**Життєвий цикл.**
1. Знахідка → сюди, у форматі A-запису Cookbook (готова до вставки, не чернетка).
2. Номер `A**nn**` — **кандидатський** (позначено `(cand.)`), фіналізується при мерджі.
3. При розпилі Cookbook на частини — цей буфер розбирається **тим самим проходом**,
   кожен запис іде у свій розділ. Після мерджу запис звідси видаляється.

**Правило.** Буфер — не архів. Якщо запис лежить тут довше 2–3 сесій і Cookbook
розпил не наближається — мерджити його в Cookbook як є, не чекати.

**Гачок від забування:** рядок-вказівник на цей файл тримати у §ПАРКІНГ кожного
чинного session summary, поки буфер не порожній.
