# Lens Stagebench Manifest — DELTA (running buffer)

**Що це.** Вхідний лоток для нових записів `Lens_stagebench_manifest.md` —
рівно те саме, що `Lens_cookbook_delta_running.md` робить для Cookbook.

**Навіщо окремий буфер, а не файл на вузол.** Без нього кожна знахідка про стенди
породжує новий документ (`..._delta_Node2_2.md`, `..._delta_Node3.md`, …), і за кілька
вузлів тека заростає. Буфер дає стелю: **один файл на канон-ціль**, скільки б знахідок
у нього не лягло.

**Життєвий цикл.**
1. Знахідка → сюди, у форматі готового запису маніфеста (не чернетка).
2. Мердж — у governance-чаті, не в продуктовому. Після мерджу запис звідси видаляється.
3. Порожній буфер лишається у теці з самою шапкою — він багаторазовий.

**Правило.** Буфер — не архів. Лежить довше 2–3 сесій — мерджити як є.

**Гачок від забування:** рядок-вказівник на цей файл тримати у §ПАРКІНГ кожного
чинного session summary, поки буфер не порожній.

## Д-2 · до §3 п.13 (в) — після замороження стенда й порту valuesLOCK стає джерелом (EquipLens S37, 20.11.2026)

**Правило:** коли стенд заморожено й продукт портуємо (стенд більше не крутять), `valuesLOCK` — **єдине джерело чисел**: вимога (в) «у valuesLOCK **і** в регістр стенда одним ходом» знімається, новий вирок — правкою рядка valuesLOCK. Генератор «засів → valuesLOCK» лише **засіває** (файла нема) і перезаписувати відмовляється; форму файла судить прилад збірки (рядок за формою · дубль · не-число · позначка «на межі» ≡ вирок · підсумки ≡ рядкам), бік стенда — окремо: стенд справді заморожений (ім'я й md5 з шапки файла), кожен ключ засіву має рядок, новий вирок — ⓘ, не ✗. **Чому:** два джерела після порту розходяться за день (designsystemscollective.com «Design Token SSOT: Figma or Code?», 20.11.2026); перегенерація з незмінного засіву мовчки стерла б вироки після порту. Практика — файл у git єдиний, руками пишеться лише він, решта генерується (martinfowler.com «Design Token-Based UI Architecture», 20.11.2026). **Як перевірити:** правка значення без підсумків → ✗ форми; з ними → ✓ і ⓘ «новий вирок: <ключ>»; `--values` при наявному файлі → ✗ «не перезаписує». **Звідки:** `EquipLens:tools/build.py` · `EquipLens:tools/stand_inventory.py` (`--values`), рішення Konst 20.11.2026 (`EquipLens:lens/BUILD-1_brief.md` §3).
