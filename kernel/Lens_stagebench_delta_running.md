# Lens Stagebench Manifest — DELTA (running buffer)

**Що це.** Вхідний лоток для нових записів `Lens_stagebench_manifest.md` —
рівно те саме, що `Lens_cookbook_delta_running.md` робить для Cookbook.

**Навіщо окремий буфер, а не файл на вузол.** Без нього кожна знахідка про стенди
породжує новий документ (`..._delta_Node2_2.md`, `..._delta_Node3.md`, …), і за кілька
вузлів тека заростає. Буфер дає стелю: **один файл на канон-ціль**, скільки б знахідок
у нього не лягло.

**Життєвий цикл.**
1. Знахідка → сюди, у форматі готового запису маніфеста (не чернетка).
2. Мердж — у governance-чаті, не в продуктовому. Після мерджу запис звідси видаляється.
3. Порожній буфер лишається у теці з самою шапкою — він багаторазовий.

**Правило.** Буфер — не архів. Лежить довше 2–3 сесій — мерджити як є.

**Гачок від забування:** рядок-вказівник на цей файл тримати у §ПАРКІНГ кожного
чинного session summary, поки буфер не порожній.
