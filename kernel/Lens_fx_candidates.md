## FX-1 · Border Beam 🟡

- **джерело:** https://beam.jakubantalik.com — Jakub Antalik. Оригінал = React-компонент («animated glowing border beam, sizes / color variants / themes»).
- **механіка:** `conic-gradient` із анімованим кутом + маска рамки (`padding-box` XOR `content-box`). Кут анімується через зареєстровану custom-property: `@property --beamA{syntax:'<angle>'}`. Без цього реєстру кут не інтерполюється — властивість анімується стрибком.
- **стек:** ✅ чистий vanilla CSS, нуль JS-залежностей. React у джерелі — обгортка, не суть.
- **вартість кадру:** ⚠️ **per-frame repaint по периметру**. Це родина A70/A72: градієнт на рамці перемальовується щокадру.
- **де безпечно:** **статичний одиничний** елемент поза скролом під час анімації.
  - StockCheck: CTA `.btn-copy` у FILL (кандидат E у бенчі `StockCheck_ctareward_bench_v1.html`).
  - Потенційно: острівець, одиничний бейдж у шіті.
- **АНТИ:** 🔴 Home-картки (14+ у скролі) · будь-який елемент у списку · будь-який елемент, що одночасно їде layout-driven рухом. Прямий прецедент провалу цього класу — bannerJank (14 карток repaint щокадру = 30–40 ms спайки на XS).
- **платформа `[07.2026]`:** анімація custom-property через `@property` — Safari 16.4+ / Chrome 85+. *Тригер перевірки: підтримка на iPhone XS / iOS 18 при першому реальному порті.*
- **вердикт:** 🟡 кандидат. Механіку відтворено у бенчі v1. Потрібен device-погляд + frame-gap, якщо піде в продукт.
- **зв'язок:** A70 (обведення під рухом) · A72 (вартість кадру) · wsd 2.4 (bench/harness).

## FX-2 · Liquid metal 🔴

- **джерело:** https://metal.jakubantalik.com — «real-time WebGL metal shader effect for buttons, three presets, one slider».
- **механіка:** справжній WebGL-шейдер у `<canvas>`.
- **стек:** 🔴 чужий. Вимагає canvas + GL-контекст на кожну кнопку.
- **вартість кадру:** GPU-контекст + постійний render-loop. На iPhone XS у PWA це батарея й пам'ять за нуль функціональної користі.
- **вердикт:** 🔴 **не портуємо.** Але враження «металу/скла» у нас уже частково зроблене без GL: багатостоповий градієнт + `background-position` (материальність γ′, Frosted-Liquid острівця). Якщо колись захочеться підсилити — рухати цю вісь, не WebGL.
- **зв'язок:** `StockCheck_materiality_valuesLOCK.md` (γ′) · `StockCheck_island_glass_FINDINGS.md`.

## FX-3 · Thinking orbs 🔴

- **джерело:** https://orbs.jakubantalik.com — «dotted thought-orb loading indicators for AI and agent UIs, six states, two sizes, auto dark/light».
- **механіка:** точкові орби, CSS/canvas-анімація стану очікування.
- **призначення:** індикатор «модель думає» для AI/agent-інтерфейсів.
- **вердикт:** 🔴 **не потрібно.** У Lens-продуктах немає стану, який це обслуговує: усі операції локальні й миттєві. Єдиний реальний асинхрон у StockCheck — `fetch` самоперевірки версії (Node 2.2), і там уже стоїть device-locked `fx-duo`. Заводити другий словник очікування = дві мови для одного стану.
- **зв'язок:** Node 2.2 `fx-duo` (самері b26_1 §2).

## Правило відбору (єдиний фільтр для цього файла)

Ефект переїжджає з цього файла у Cookbook **тільки** пройшовши всі чотири:
1. **механіка розкладена** — ми знаємо, якою технікою це зроблено, а не тільки як виглядає;
2. **vanilla без чужого стека** — нуль фреймворків, нуль GL-контекстів;
3. **вартість кадру виміряна** в тому місці, де його ставимо (не «в теорії композитний»);
4. **device✓ на обох темах** — арбітр як завжди.

Не пройшов — лишається тут як кандидат. Це не борг і не TODO: **реєстр натхнення не мусить порожніти.**
