## FX-1 · Border Beam 🟡

- **джерело:** https://beam.jakubantalik.com — Jakub Antalik. Оригінал = React-компонент («animated glowing border beam, sizes / color variants / themes»).
- **механіка:** `conic-gradient` із анімованим кутом + маска рамки (`padding-box` XOR `content-box`). Кут анімується через зареєстровану custom-property: `@property --beamA{syntax:'<angle>'}`. Без цього реєстру кут не інтерполюється — властивість анімується стрибком.
- **стек:** ✅ чистий vanilla CSS, нуль JS-залежностей. React у джерелі — обгортка, не суть.
- **вартість кадру:** ⚠️ **per-frame repaint по периметру**. Це родина A70/A72: градієнт на рамці перемальовується щокадру.
- **де безпечно:** **статичний одиничний** елемент поза скролом під час анімації.
  - StockCheck: CTA `.btn-copy` у FILL (кандидат E у бенчі `StockCheck_ctareward_bench_v1.html`).
  - Потенційно: острівець, одиничний бейдж у шіті.
- **АНТИ:** 🔴 Home-картки (14+ у скролі) · будь-який елемент у списку · будь-який елемент, що одночасно їде layout-driven рухом. Прямий прецедент провалу цього класу — bannerJank (14 карток repaint щокадру = 30–40 ms спайки на XS).
- **платформа `[07.2026]`:** анімація custom-property через `@property` — Safari 16.4+ / Chrome 85+. *Тригер перевірки: підтримка на iPhone XS / iOS 18 при першому реальному порті.*
- **вердикт:** 🟡 кандидат. Механіку відтворено у бенчі v1. Потрібен device-погляд + frame-gap, якщо піде в продукт.
- **зв'язок:** A70 (обведення під рухом) · A72 (вартість кадру) · wsd 2.4 (bench/harness).

## FX-4 · Gooey / liquid morph menu 🟡

- **джерело:** класична техніка metaball (`feGaussianBlur` + `feColorMatrix` на контраст альфи); мокап оператора 13.08.2026 — розгортання двох дій угору з Excel-кнопки CTA-ряду StockCheck.

- **вердикт:** 🟡 кандидат **без місця**. Механіка зрозуміла, дім у продукті не знайдено — лежить до випадку, де ефект нічому не конкурує.

### FX-5·спільне — принцип, що тримає всі числа нижче 🔑

Світла тема користується **білим значно щедріше** за темну, і це наскрізно:

| | ТЕМНА | СВІТЛА |
|---|---|---|
| `surface-1 / 2 / 3` | `rgba(255,255,255, .08 / .10 / .14)` | `.50 / .60 / .70` |
| драбина `inset` | `.10 / .15 / .25 / .40` | `.60 / .70 / .80 / .90` |
| `border-subtle / medium` | `rgba(255,255,255, .18 / .30)` | `rgba(0,0,0, .08 / .12)` |

Читається так: на **темній** скло — тонка біла вуаль; на **світлій** — молочне тіло над тонованим фоном. Це не інверсія одного набору, це дві різні речовини. Прямий інстанс `A39`, але на осі, якої ми не пробували: не «те саме число інакше читається», а **«та сама роль вимагає різного порядку величин»** (×5 по білому).

⚠️ Контрінтуїтивно. Наш рефлекс — «на світлому білий inset нічого не дасть». Їхній код каже протилежне, і скрін №2 (світла тема) це підтверджує окомірно: молочна кромка карток.

### FX-5a · Драбина `inset` як ТОКЕН, а не число 🟡

```
--gl-inset-subtle : inset 0 1px 1px rgba(255,255,255, D .10 / L .60)
--gl-inset-medium : inset 0 1px 1px rgba(255,255,255, D .15 / L .70)
--gl-inset-strong : inset 0 1px 2px rgba(255,255,255, D .25 / L .80)
--gl-inset-milk   : inset 0 1px 2px rgba(255,255,255, D .40 / L .90)
```

Кожен компонент дописує потрібний щабель **останнім шаром** у власний `box-shadow`:
`box-shadow: 0 4px 12px rgba(0,0,0,.08), var(--gl-inset-subtle)`.

**Геометрія спільна, розходиться тільки альфа** — два кроки по blur (`1px` → `2px`), решта стала.

**Чому це важливо нам.** У нас те саме поняття існує, але **окремим числом на кожному елементі** — тому бульбашка, острівець і капсула не пов'язані нічим, крім пам'яті оператора. Драбина дає **спільну комірку** без спільних чисел: мова одна, щабель кожен обирає свій. Це рівно те, що `A98` вимагає від «родини», і рівно те, чого EquipLens просив словами «зробити родичів».

- **де безпечно:** будь-де. `inset`-тінь не фон і не бордер → не має жодного з трьох механізмів `A101`.
- **зв'язок:** `A98` (родина = мова, не числа) · `A101-б` (щаблі від однієї кромки **перекриваються**, не сумуються — драбина мусить відлічуватись від внутрішнього краю попереднього) · `A45`.
- **вердикт:** 🟡 кандидат, найсильніший у пакеті.

### FX-5b · Прожектор замість плитки — ТРЕТІЙ спосіб проти A99 🟡

`A99` дає бінарну вилку: коло → радіальний градієнт (є полюс), прямокутник → лінійний (полюса немає). GlassKit обходить її **третім** способом: полюса не шукають, його **призначають у центрі**.

```
.item.is-active::before { content:''; position:absolute; inset:0;
  border-radius:inherit; pointer-events:none; z-index:0;
  background:radial-gradient(circle at center,
     color-mix(in srgb, SPOTLIGHT 28%, transparent)  0,
     color-mix(in srgb, SPOTLIGHT 10%, transparent) 55%,
     transparent 100%) }
.item > * { position:relative; z-index:1 }
```

**Активний таб — акорд із п'яти каналів, не заливка:**

| # | канал | значення |
|---|---|---|
| 1 | штрих іконки | → `--gl-color-primary` |
| 2 | **світіння гліфа** | `filter:drop-shadow(0 0 6px color-mix(in srgb, primary 35%, transparent))` |
| 3 | лейбл | → `primary` |
| 4 | **крапка** `::after` під іконкою | `4×4px`, `bottom:-6px`, `primary`, `box-shadow:0 0 6px color-mix(primary 50%)` |
| 5 | **прожектор** `::before` | таблиця вище |

🔑 **Канали 4 і 5 — взаємовиключні, не складені.** У плаваючому варіанті стоїть
`.glass-tab-bar--floating .is-active .icon::after{display:none}` — крапка **гаситься**, коли вмикається прожектор. Пришвартований бар несе крапку, плаваючий — прожектор. Одна робота, два носії, вибір за контекстом. Це готовий детектор проти нашої типової помилки «додати обидва, бо обидва гарні».

**Руху немає.** Єдина анімація — `transition: all .25s ease` на кольорах. Жодного `transform`, жодного підйому. Відчуття «його піднімає» — **оптичне**, від світіння гліфа й появи прожектора. Це самостійна знахідка: підйом без руху коштує нуль кадрів.

- **АНТИ:** 🔴 не ставити прожектор і крапку разом · 🔴 `filter` на гліфі створює containing block (родина `FX-4`) — під ним не має бути `fixed`-нащадків.
- **зв'язок:** `A99` (третій рядок вилки) · `A67.1` (card-select) · `A56` (bottom-nav).
- **вердикт:** 🟡 кандидат. Прямий претендент на виділення активного табу EquipLens.

### FX-5c · Волосинка, що згасає на кінцях 🟡

Верхнє ребро картки — окремий `::before`, **не** бордер:

```
::before { top:0; left:10%; right:10%; height:1px; z-index:1;
  background:linear-gradient(90deg, transparent 0,
     rgba(255,255,255,.5) 30%, rgba(255,255,255,.6) 50%,
     rgba(255,255,255,.5) 70%, transparent 100%) }
```

**П'ять стопів, не три.** Пік по центру (`.6`), плечі (`.5`), згасання до нуля на 0/100%. Плюс сама смуга обрізана до `10%…90%` ширини — тобто згасання **подвійне**: геометричне (inset) і тональне (градієнт).

Другий інстанс того самого прийому — роздільник `.glass-divider`: та сама геометрія на стопах `20/50/80%`, але кольорами токенів країв замість білого.

**Різниця, яку варто назвати:** лінія на всю ширину читається як **рамка**; лінія зі згаслими кінцями — як **відблиск**. `A45` каже «ridge градієнтом, не лінією», але це про градієнт **упоперек**; про згасання **вздовж** у каноні немає нічого.

- **зв'язок:** `A45` (ridge) · `A66` (асиметрія елевації) · наш `.el-hdiv` тримає **третю** мову (суцільна лінія з вертикальним врізом) — при перейнятті звести до однієї.
- **вердикт:** 🟡 кандидат, найдешевший у пакеті.

### FX-5d · `color-mix` замість прибитих `rgba` 🟡

```
--gl-border-focus : color-mix(in srgb, var(--gl-color-primary) D 60% / L 50%, transparent)
--gl-shadow-focus : 0 0 0 3px color-mix(in srgb, var(--gl-color-primary) D 30% / L 25%, transparent)
```

Один акцентний токен → усі похідні прозорості **виводяться**, а не прописуються. Для нашої двотемної біди це знімає частину пар `…L`/`…D`: лишається пара **відсотків**, а не пара кольорів.

**Фокус поля — акорд із чотирьох каналів** (це відповідь на запит оператора «виділити поле пошуку при обраності, як на сайті»):

```
.glass-input:focus { border-color: var(--gl-border-focus);   /* 1 колір канта */
                     background:   var(--gl-surface-3);      /* 2 поверхня +1 щабель */
                     box-shadow:   var(--gl-shadow-focus),   /* 3 зовнішнє кільце 3px */
                                   var(--gl-inset-medium) }  /* 4 драбина +1 щабель */
```

Помилковий стан перевикористовує ту саму форму з іншим токеном: `0 0 0 3px color-mix(in srgb, error 25%, transparent)`. Кільце — **не** `outline` (у них `outline:0`), бо `outline` не гнеться по `border-radius` однаково на всіх рушіях і не складається в один `box-shadow` із драбиною.

- **платформа `[08.2026]`:** `color-mix(in srgb, …)` — Safari 16.2+. iPhone XS / iOS 18 покриває. *Тригер перевірки: при першому реальному порті.*
- **зв'язок:** `A39` · `A91` (одна альфа) · `A73` (хіт-експандер — фокус ≠ прес).
- **вердикт:** 🟡 кандидат.

### FX-5e · Фон-аврора — і головне застереження 🔴 для картинки, 🟡 для техніки

`.glass-bg` = база + **три** радіальні еліпси + дві світлові смуги + тепле світіння:

```
radial-gradient(ellipse at 20% 40%, AURORA-1 0, transparent 55%),
radial-gradient(ellipse at 80% 65%, AURORA-2 0, transparent 50%),
radial-gradient(ellipse at 50% 20%, AURORA-3 0, transparent 50%),
linear-gradient(170deg, BG-LIGHT 0, BG-DARK 100%)
```

| токен | ТЕМНА | СВІТЛА |
|---|---|---|
| база `170deg` | `#1b3e50` → `#0e2530` — **петроль, не чорний** | `#f5f7fa` → `#e8ecf1` — холодний, **не білий** |
| аврора 1 (20% 40%) | `rgba(60,160,160,.25)` | `rgba(100,200,220,.15)` |
| аврора 2 (80% 65%) | `rgba(200,140,60,.12)` **тепла** | `rgba(240,180,100,.10)` |
| аврора 3 (50% 20%) | `rgba(80,180,200,.18)` | `rgba(120,200,230,.12)` |
| смуги 1 / 2 | `rgba(90,210,200,.14)` / `rgba(110,200,190,.10)` | `.10` / `.08` |
| тепле світіння | `rgba(220,160,70,.10)` | `rgba(240,180,100,.08)` |

⚠️ **Пастка іменування:** `--gl-color-bg-light` / `-dark` означає **світлий і темний кінець градієнта**, а не тему. Обидва токени існують усередині кожної теми. Читати як «тема» = переплутати все.

🔴 **Застереження, важливіше за самі числа.** Їхнє скло стоїть на барвистій розмитій підкладці. **Половина вау — це фон, а не компонент.** Це буквально `A100` / `glass_FINDINGS §10a`: скло не має власного вигляду. У EquipLens під бульбашкою — білий список на майже білому; ті самі числа там дадуть бліду пляму.

**Чесний висновок: техніку беремо, картинку не переносимо.** Якщо колись схочеться такого ж вау — правильний важіль **у фоні екрана**, а не в бульбашці. Це рішення продукту, воно конфліктує з тезою «аркуш», і його дім — `glass_FINDINGS §10c`, де воно вже стоїть відкритим.

- **вердикт:** 🟡 техніка (важіль на стенді, крок К1) · 🔴 картинка (не переносимо).

## Правило відбору (єдиний фільтр для цього файла)

Ефект переїжджає з цього файла у Cookbook **тільки** пройшовши всі чотири:
1. **механіка розкладена** — ми знаємо, якою технікою це зроблено, а не тільки як виглядає;
2. **vanilla без чужого стека** — нуль фреймворків, нуль GL-контекстів;
3. **вартість кадру виміряна** в тому місці, де його ставимо (не «в теорії композитний»);
4. **device✓ на обох темах** — арбітр як завжди.

Не пройшов — лишається тут як кандидат. Це не борг і не TODO: **реєстр натхнення не мусить порожніти.**
