## §3 Схема репо ↔ Project — вирішено

**Репо реорганізовано Konst:** `kernel/` 22 · `products/` 19 · `archive/` 81.
G1 по всіх 41 файлах ядра й продуктів: **40/41** несуть «живе доки»
(виняток `products/QR_Lens_export_contract_v1_1.md` — дописати).

**Знайдено корінь подвійної роботи.** Konst робив **обидві** речі: підключав репо як
GitHub-джерело **і** заливав ті самі файли вручну. Це два різні механізми — вони не
замінюють один одного, а співіснують, звідси дублі й подвійна capacity.

**Ухвалено й виконано в сесії:**

| дія | результат |
|---|---|
| `archive/` відключено від Project | **76% → 44%** |
| ручні дублі підключених файлів видалено | **44% → ~30–35%** |
| оновлення підключеної теки | кнопка **Sync**, не перезалив |
| вручну в Project лишається | живі самері · живі білди · jsdom-матриці · `icon_gen.py` |

**Фолбек-драбина доступу до архіву** (5 рівнів) — заведена в `Lens_INDEX` §8.
Рівень 0: `kernel`+`products` уже в Project, мережа не потрібна для 95% роботи.
Рівень 1 `api.github.com` **ловить 403 rate limit** (перевірено). Рівень 2 HTML-сторінка
`github.com/tree` — працює під лімітом. **Рівень 3 — головний:** `Lens_ARCHIVE_INDEX.md`
лежить у `kernel/`, тобто дає точні імена **без мережі**; маючи ім'я, список не потрібен.
Той самий принцип, що й 1.10 — звірка з оголошенням замість запиту до системи, яка може мовчати.

**Розмежування, яке знімає плутанину:** capacity Project ≠ контекст чату. Файл у Project
не витрачає контекст, доки не прочитаний. Два різні бюджети.

### G11 — цілісність буфера (новий гейт)

Прямий нащадок 14.29 і перше застосування **1.10** до інструмента:

- **(a) оголошення ⟂ факт.** Кожен буфер несе рядок `**ЛОТОК: N запис(ів).**`; гейт звіряє
  оголошене з фактичним числом H2-заголовків. Ловить **саму втрату**: якщо паралельна сесія
  затерла запис, число розійдеться.
- **(b) дубль номера.** `Д-N` / `A-NN`, що трапляється двічі, — слід колізії.

**Перевірено на обох базах** (вимога «детектор мусить бути правильним»):
зламана → ✗ обидві гілки спрацювали · чиста → ✓ 3/3, хибних ✗ немає.

**Межа гейта, названа чесно:** (b) ловить лише **слід** колізії — якби друга сесія
перезаписала файл цілком, дубля не лишилось би. (a) ловить саму подію, але **тільки якщо
шапку оголошення дописують при мерджі**. Це не автоматика, це дисципліна з детектором.
