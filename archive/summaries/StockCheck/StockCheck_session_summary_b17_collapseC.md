## 1. Що зроблено

Імплементовано §5-B (collapse-on-scroll). Модель (B) була залочена device v2 як **модель**;
ця сесія шукала **механіку**. Пройдено три механіки, обрано третю.

| | механіка | що робить | вирок |
|---|---|---|---|
| A | snap | клас + CSS-transition на `grid-template-rows` | відхилено |
| B | scroll-linked | `(1−p)fr` щокадру | відхилено |
| **C** | **composite slide** | **`translate3d` острівця, `opacity` бренду** | **ОБРАНО** |

A і B по frame-gap виявились рівними (27–34 ms) — різниця, яку було чути, йшла не від
пропускної здатності, а від розподілу вартості в часі. C прибирає вартість, а не переставляє її.

## 2. Рішення (locked)

1. **§5-B механіка = C**, scroll-linked до `scrollTop`, Δ = виміряний `headH`.
2. **`msh` (гасіння тіней у русі) — у продукт НЕ йде.** Прилад відповів «тіні не винні».
3. **Мертві важелі C** (`ease`/`dur`/`fade`/пороги/`collPadT`) — вирізати з продукту,
   лишити в стенді.
4. **`trayRad = 22` лишається залоченим**, ретест скасовано: у C таця не рухається відносно
   острівця, преміса FINDINGS §6b відпала.
5. **Дев-панель — тимчасова**, знімається по маркерах `DEV-PANEL START/END`.

## 3. Структурні зміни в продукті (не косметика)

- `padding-top: safe-area+10` переїхав з `.isl-brand` на `.isl` (у спокої дельта нуль).
- `.isl-brand` загорнуто в `.isl-head`.
- **spacer переписано на інваріанти** (`padT + headH + tierH + border`) — більше не залежить
  від висоти острівця. Це виправлення проти прецеденту 14.20.
- Хуки на `renderHome` / `renderTop` / `show` — обгортками, без правки тіл.
- §4-port-1 усі 4 шари на місці (clamp · overscroll · чистий rest · frame-gap).

## 5. Дефект, знайдений після заміру (виправлено в b17_3, НЕ device-verified)

У C `opacity` бренду пишеться щокадру, а на ній жила `transition: opacity 140ms` — кожен кадр
стартував нову транзицію. Клас `.linked` гасив транзиції тільки для B, `.slide` — ні.

```css
/* b17_3 */
.isl.linked .isl-head,.isl.linked .isl-head>.isl-brand,
.isl.slide  .isl-head,.isl.slide  .isl-head>.isl-brand{transition:none}
```
Це найімовірніший кандидат у пояснення і викидів 34/38, і «бренд з'являється анімацією»
при повільному скролі. **Перший пункт наступної сесії — переміряти.**
