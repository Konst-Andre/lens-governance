## §2. РІШЕННЯ СЕСІЇ

### 2.1 Порт 1:1 — лінія контенту фільтрів 20px (крок 8px проти бренд-ряду)
Таця: `margin:0 6px` + ряди зберігають власні `padding:0 14px` → контент на **20px**, бренд-ряд на 12px.
Коментар у стенді стверджував протилежне («лінія не їде») — **коментар розходився з кодом**; арбітр бачив і схвалив саме 20px. На девайсі читається як **вкладеність**, не як розсинхрон.

### 2.2 Матеріал через токени `--m-*`, не через per-theme правила
Причина: темна тема в продукті живе у **двох** місцях (`[data-theme="dark"]` + `@media (prefers-color-scheme:dark)`). Токени концентрують дублювання у блоках, які вже дубльовані.
**Побічно полагоджено наявний баг паритету:** `act` (netbtn + `•••`) мав explicit-dark **без** auto-dark дзеркала (A69) → при системній темній без ручного тоглу кнопки лишались світлими.

### 2.3 Темні градієнти запечені в hex — `color-mix` знято з-під `backdrop-filter` ПОВНІСТЮ
Зроблено більше, ніж планувалось: окрім `bc/chip/act` — ще `srch` (`#111916`) і **тон таці**
(`color-mix(in srgb,transparent 77%,var(--card))` = точно `rgba(24,34,30,.23)`).
Світла лишилась на `color-mix` (дешева, +2.0 ms, зв'язок з токенами збережено).
**Ціна:** зв'язок темних градієнтів з `--surface-3`/`--card` розірвано → при зміні цих токенів перерахувати hex (застереження стоїть у коментарі коду).

### 2.4 Cookbook НЕ приймає новий A-запис — усе лягло в наявне
Початковий план («Cookbook island A-entry») — **знято за запереченням Konst** про роздутість Cookbook (75 A-записів, у черзі на чистку). Звірка підтвердила заперечення:
- §5.1 радіус → **FINDINGS §6b** (острівцева мова, поза острівцем сенсу не має)
- §3.1 + §3.3 → **доповнення наявної A66** (recess-виняток уже там)

**Правило, яке з цього випливає:** канон-таргет обирається за **областю дії**, а не за «це важливо → в Cookbook». Крос-Lens універсальне → Cookbook; специфічне для патерну → файл патерну.

### 2.5 §3e закрито протилежно гіпотезі
`netbtnPlate = **ON**`. Гіпотеза «подвійне тіло» (кнопка з власним якорем `ntile` не потребує плашки) **не підтвердилась** на девайсі. Правило лишається чинним для безякірних випадків, але не поширюється на 44px-кнопку з внутрішнім 35px-тайлом.

### 2.6 Скрол-модель — вибору немає, він уже зроблений
FINDINGS §5: **(B) collapse-on-scroll ✅ ЗАЛОЧЕНО (device v2)**. (A) unlock відхилена (втрата доступу до фільтрів у counting-tool), (C) two-tier fixed — антипатерн.
`valuesLOCK §8` називав це «окремою задачею» без згадки, що модель обрана → у чаті двічі прозвучало хибне «вибір A/B». Виправлено в §8.

## §5. УРОКИ СЕСІЇ (generalizable)

1. **Стартове повідомлення сесії — теж джерело сталого.** План порту прийшов із самері й містив три хибні преміси (`.tier` як ціль · `--b-*` «вже є» · «вибір A/B» замість залоченої моделі). Усі три спіймані **тільки** грепом реального коду й читанням FINDINGS. → wsd 12.1 діє і на власні самері, не лише на чужі підсумки.

2. **Коментар у коді може розходитись із самим кодом — арбітр бачить КОД.** Коментар стенду стверджував «лінія контенту не їде», CSS робив протилежне. Device-рішення прийнято по **рендеру**. → при порті 1:1 звірятись із рендером, не з коментарем-наміром.

3. **Ім'я класу перевіряти грепом ПЕРЕД портом, завжди.** `.tier` виявився зайнятим (рядок OTC/IW у картці). Це другий випадок у цьому ж файлі після `.brand`→`.sc-brand`. → NAME-GUARD як обов'язковий крок порту, не як реакція на баг.

4. **Канон-таргет обирається за областю дії, не за важливістю.** Роздутий каталог — симптом того, що туди складали все важливе. Питання: «це працює поза цим патерном?» Ні → дім у файлі патерну.

5. **Відхилену ставку не закривати назавжди, якщо реалізація була дефектною.** Таця програла у bench v1 через порушений A65-спліт, а не через саму ідею; у v2 виграла. → переперевіряти після фіксу реалізації.

6. **Токенізація per-theme значень ловить баги паритету безкоштовно.** Перехід на `--m-*` виявив `act` без auto-dark дзеркала — баг, який ніхто не шукав.

7. **«Спростити вкладений color-mix» ≠ завжди можливо алгебраїчно.** Верхній стоп градієнта зводиться в один рівень точно; нижній містить три кольори і одним `color-mix` не виражається. → або кінцевий hex, або лишити вкладеність свідомо.
