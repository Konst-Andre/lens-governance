## §6 · СКРИПТ ДЛЯ НАСТУПНОЇ ПРОПОЛКИ — карта ваг із урахуванням fences

```python
import re
s=open('Work_Standard.md',encoding='utf-8').read(); L=s.split('\n')
idx=[]; fence=False
for i,l in enumerate(L):
    if l.startswith('```'): fence=not fence; continue
    if not fence and re.match(r'^#{1,2} ',l): idx.append(i)
idx.append(len(L))
rows=[(L[idx[k]].strip()[:70], len('\n'.join(L[idx[k]:idx[k+1]]).encode()))
      for k in range(len(idx)-1)]
for t,b in sorted(rows,key=lambda r:-r[1])[:12]: print(f'{b:6d}  {t}')
```

Вирок ставиться **не за вагою**, а за питанням: *«тригер цього правила спрацьовує
в будь-якій сесії — чи в одній із десяти?»* Друге = виселити в тематичний дім,
лишивши номер живим як маршрут.
