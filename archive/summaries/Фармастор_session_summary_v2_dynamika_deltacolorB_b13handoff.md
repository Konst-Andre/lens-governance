## §1 · ГОЛОВНИЙ РЕЗУЛЬТАТ — Δ-колір Динаміки залочено = МОДЕЛЬ B (harness device✓)

Реопен §5.1: колір Δ-чіпа рядка + tally-плитки **більше НЕ «дистанція до норми», а «недобір».**

**Обрано B · critK=0 · labels=norm** (звірено на девайсі Konst, обидві теми, реальні числа).

**Логіка B** (`s=max(0,MSL−V)` — скільки бракує до норми; 0 якщо ≥норми):
- `sF=max(0,nF−f)`, `sT=max(0,nT−t)`
- `t===0` → **crit** (порожня полиця)
- `sF===0 && sT===0` → **stable / muted** (обидва ≥ норми)
- `sT<sF` → **improve / accent** (недобір скоротився/закрився — навіть якщо ще нижче норми, траєкторія ↑)
- `sT>sF` → **degrade / warn** (недобір виріс / впав у дефіцит)
- `sT===sF>0` → **stuck / warn** (застряг нижче)

**Значення-параметри (залочені):**
- **critK = 0** — лише порожня полиця = crit-червоний. Фіксований поріг 1-6 **відкинуто** (не масштабується під per-SKU норму: `sT≥3` = 100% для MSL3, але 37% для MSL8 → довільно). «Все червоне» **відкинуто** (вбиває тріаж; червоний має лишатись рідкісним = терміновим = порожня).
- **labels = «до норми / від норми / без змін»** (не «ближче/далі», не «дефіцит») — узгоджено з наявним локом §5.1 (line 159), пережив реопен. Причини: ширина (коротше, nowrap-safe під Dynamic Type), один словник (норма вже всюди), стрілка ↑↓ несе напрям.
- **tally = ТРАЄКТОРІЯ** (краще/гірше/без змін), не рядок-колір: `stuck` (нижче, незмінно між візитами) → «без змін», хоча рядок warn (СТАН). Вердикт-слово шапки авто-похідне від tally.

**Ядро B — розчеплення колір↔стан:**
- **Δ-колір = ТРАЄКТОРІЯ** (недобір скоротився чи виріс).
- **«нижче норми ЗАРАЗ» = СТАН** — ловлять фільтр «Проблемні» (§5.4, `sT>0`) + видиме сире число.
- Бонус: B **вирівнює «Проблемні» під §5.4** (нижче норми=`sT>0`, абсолют), тоді як A фільтрувала за траєкторією (суперечило §5.4).

**Чому не A:** дистанція фарбувала падіння під норму зеленим (7→4/MSL5 = «наблизився» = green, хоча 4<5 = треба дозамов). На девайсі не читалось. 4 дискримінуючі кейси Konst (де A↔B інвертуються): 7→4 · 9→2 · 6→5 · 4→7 (MSL5).
