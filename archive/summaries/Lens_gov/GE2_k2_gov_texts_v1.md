### 12.6 — тригер (після заголовка)

```
**Тригер.** (1) Створюється або оновлюється запис Cookbook / специфікації з коду. (2) Device-фікс змінює interaction-код (passive-прапори · guards · пороги · `_swiped` · тривалості) у патерні, що вже має запис Cookbook.
```

### 12.6 — детектор (у кінці тіла)

```
**Детектор (К2).** (1) У записі Cookbook, створеному чи зміненому в ході, `grep` на код-точку (`р.NNN` / `функція` / клас) = 0 → ✗ «запис без джерела». (2) Хід device-фікса interaction-коду: ключова сигнатура фікса (ім'я прапора, поріг, guard) → `grep -F` у відповідному томі `kernel/cookbook/`; 0 входжень → ✗ «Cookbook не пересинхронено», фікс не закритий. Рядок цієї звірки — у звіті ходу фікса.
```

### 12.7 — тригер

```
**Тригер.** Цілий компонент (не окреме значення) канонізується з коду в Cookbook або специфікацію.
```

```
**Детектор (К2).** Перед фіналізацією запису — `grep -F` кожної сигнатури з capture-checklist (shadow · gradient · `@keyframes` · aria · кожен `addEventListener`) у коді-джерелі і в записі. Сигнатура є в джерелі й відсутня в записі → ✗ «внесено частково». Число звірених сигнатур — у звіті ходу.
```

```

```

## §4 Знахідки пілоту

**Ф-6 · `G16` дає хибний ✓ на будь-якому підрядку «етектор» / «К2».** Доведено `--inject` 17.09.2026 на копії `3a8a36a`: рядок «Детектор ще не написано.» у кінці `12.18` → `12.18` зникає з переліку (5 → 4). Родина `G16-1`. Замір на живому каноні: із правил, що G16 зараховує як «з детектором», **без** заголовка `**Детектор…**` — лише 3: `wsd 1.11` · `gov 12.12` · `gov 12.17`. Масштаб малий, але вставки цього пілоту мусять мати заголовок `**Детектор (К2).**`, і кандидатом у фікс гейта є саме вимога заголовка. Три слабкі правила — прочитати в тому ж проході, що й 36 wsd.

**Ф-7 · `12.16` «Межа» ⟂ практика.** Правило: «прополка (видалення, перенос) вимагає читання й окремого поштучного погодження — скриптом не робиться». Практика G-C3 (архів 34 файлів) і G-D (`gd_step2_prune_v2.py`, буфер 33 → 16 KB) — прополка **скриптом** після читання і погодження. Суть правила (читання + поштучне погодження) дотримано, букву («скриптом не робиться») — ні. Рекомендований вирок: уточнити межу, а не забороняти практику.

```
**Межа 🔒.** Так робиться **дописування** без читання тіла. **Прополка** (видалення, перенос) вимагає читання цільового фрагмента цілком і поштучного погодження **до** запуску; виконується тим самим скриптом за якорем, з read-back.
```

Ф-7 змінює зміст правила, тому йде окремим рядком погодження в G-E3, не разом із детекторами.
