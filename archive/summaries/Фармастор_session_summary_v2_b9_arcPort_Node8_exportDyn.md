## 1 · ЗРОБЛЕНО ЦЬОГО СЕАНСУ

### 1.1 arc-fill ПОРТ → `Фармастор_замовлення_v2_port_b9.html` (device✓)
Портовано motion з harness у реальні home-card кільця. Було: `ringSVG(f)` малював статичний offset. Стало — дуга наливається `old→new` лише на щойно-змінене кільце.

**Механізм (реалізовано, гейти чисті, device✓):**
- **Тригер = snapshot-diff.** Module-scope `_homeSnap={px:filled}` з попереднього рендера. У `renderHome`: обчислюю `full=homeModel()`, `M=full.filter(topMatch)`; після `innerHTML` — анімую картку лише якщо `_homeSnap` не null **І** `p.state==='ready'` **І** `snap[px]!==p.filled` **І** картка видима. Перший mount (snap=null) → нуль анімацій. Зміна фільтра/області (числа ті ж) → нуль. Новоз'явлена в фільтрі (px∉snap) → не анімуємо. Наприкінці — оновлюю snap по ВСІХ px.
- **Рух:** `animRing(card,oldF,newF)` — decel-sweep `e=1−(1−t)³`, тільки `stroke-dashoffset` (A70). Старт: offset+число+`%` на old → rAF до new. Фініш: снап на rest-формулу `75−0.75·hPct(newF)`.
- **Тривалість = scale-під-дистанцію** (device-locked harness v2): `ARC={floor:600,ceil:1600,exp:1}`; `dur = floor+(ceil−floor)·(Δpp/100)^exp` (exp=1 лінійний). 0→повне=1600 (стеля=залочене), Δ35≈950, +1≈612. **Динамічні тривалості** (швидкість наливу ~стала).
- **pulse-on-full:** `@keyframes pulseF` (scale, 460ms, `cubic-bezier(.34,1.56,.64,1)`), грає лише при `newF≥83 && oldF<83`.
- **reduced-motion:** ручний guard `reduceOn()` (у b8 глоб. CSS-killer вбиває transition, не rAF) → при reduce ставимо фінал без руху.
- **arcword (%)** синхронно з count-up (як у harness).

**Правки в b9:** CSS pulse keyframe; `class="arcfill"` на fill-коло; рушій між `ringSVG`↔`homeModel`; `renderHome` split full-model + snapshot-diff блок; `APP_BUILD='v2.3.0-arc.b9'`.

**Гейти:** `node --check` ×2 OK · div 55/55 · анкери OK · absent≠0 fill-логіка не чіпалась.

**Канон-борг:** arc-fill → Cookbook A57 (expressive off-ladder) + MASTER_LOCK §5.2/§6.4 значення (scale·600·1600·lin, snapshot-diff, dashoffset-A70). Канонити в governance-чаті.

## 2 · ЗАФІКСОВАНО (обговорення → рішення; код у наст. чаті)

### 2.1 Експорт CSV — контекстний (LOCK напряму)
CSV = **тиха страховка-бекап (§4), НЕ герой.** Герой-перенос = `copyValues` (кліпборд→M), лишається.
- **Меню з FILL (одна аптека)** → лейбл «**Експорт CSV · ця аптека**» → 83 значення цієї аптеки (файл/share).
- **Меню з Home (список)** → лейбл «**Експорт CSV · усі дані (N аптек)**» → гуртовий бекап усіх аптек-з-даними (страховка від втрати localStorage). **НЕ за фільтром** (бекап = «нічого не загубити»).
- **Динамічний лейбл за контекстом** — кнопка сама каже, що вивезе. Знімає неоднозначність.

**Per-card іконка експорту — ВІДХИЛЕНО (обґрунтовано):** експорт можливий лише після заповнення (ти вже був у FILL) → «швидкий експорт з картки» = ніша (ре-експорт). Постійна іконка захаращує щільну картку, додає 2-й тап-таргет проти drill-first, підіймає рідкісну бекап-дію над первинними. Меню-контекст закриває чесно. _Опція якщо Konst наполягатиме:_ тихий **swipe-жест** ре-експорту, лише на ready/transferred — не постійна іконка. (Konst у віджеті міг обрати цю гілку — перевірити його вибір.)

### 2.3 Динаміка — інтерфейс, напрям A (TENTATIVE — re-microscope у наст. чаті)
Напруга: рядок несе багато (`SKU · від · до · Δ · колір-за-нормою`) на 375px, у accordion (кат-дільник+бренд-картка+рядок).
- **A (нахил):** праворуч `V0→V1`, поряд тонкий кольоровий **Δ-чіп** (знак+число); **колір = дистанція-до-норми** (реюз існуючого δ-чіп FILL). Компактно, колір несе сенс, сире число лишається, absent→«—» природно.
- **B (тісний):** колонки від·до·Δ в eyebrow — тісно на 375, eyebrow вже несе бренд.
- **C (концепт-макс, deferred):** bar-до-норми gauge на рядок (маркер норми + 2 точки) — кодує сенс найсильніше, але 83 gauge = шум+perf; лишити як пізню амбіцію «повний тренд по SKU» (§5.1 сама відкладає).

**Наступний крок після фіксу напряму:** harness-рядок (стани: зблизився/віддалився/стоїть/absent/явний-0, обидві теми) → device-арбітр (harness-first §5.1).

### 2.4 Динаміка — ЛОГІКА (з плану, стабільно)
- **mock-first (wsd 3.6):** dev-прапор вкидає `visits[]`-фікстуру на реальну аптеку (реальні kode, ≥2 `transferred`), edge: absent-в-одному→«—», явний 0, all+/all−/mixed, same-day overwrite. §1-контракт.
- **Вхід:** «Динаміка ›» на Home-картці (gated visits≥2, footHTML р.818) → екран `s-dyn` (лінійний, ‹назад). Per-аптека.
- **Пікер «від/до»:** дефолт останні два `transferred`.
- **Реюз accordion:** `catSec`/`brandCard`; рядок замість інпута.
