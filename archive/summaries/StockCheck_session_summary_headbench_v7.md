## 0. Що це за напрям

**StockCheck** = **не новий продукт**, а **мульти-мережева еволюція Фармастора** (ребренд + розширення).
Реюз майже всього. Мета — уніфікована «шапка» (бренд-блок + фільтр мереж) + логіка кількох мереж.
Свідомо НЕ схоже на Lens; від поточного Фармастора відрізнятись не обов'язково — це *він і є*.

## 1. Рішення (LOCKED / pending device-pick)

**Архітектура даних**
- `net` поле **вже існує** в схемі PH (`farmastor_v2_data.js`, зараз моно «Фармастор»). Мульти-мережа = populate + фільтр, не нова модель.
- **MSL scope = Option A (спільний MSL)** — LOCKED. Портфель репа (Reckitt SKU, коди Моріону національні) перевіряється в будь-якій мережі. Per-net override норм A/B/C/D — deferred (YAGNI, поки мережа реально не покаже інші таргети).
- `net` ⟂ `area`/`city` ⟂ `oTC`/`iW` — ортогональні осі. Мережа = top-level перемикач у хедері (найгрубший скоуп).
- **visits[] / snapshot-on-copy** — network-agnostic (ключ `px`). Нуль міграції.

**Бренд / айдентика**
- **Нейтральний батьківський бренд StockCheck**; колір мережі живе ТІЛЬКИ в бейдж-чипі. Тема = один нейтральний shell (НЕ перефарбовуємось під мережу). Вирішує «чий колір головний» при N мережах.
- Кандидати (pending device-pick): **іконка comet** (хвіст `taper` = поточний лідер) + wordmark **SC-caps**. `mono` відкинуто (без характеру).
- Комета параметрична: gap° · width° · checkTilt · tail(taper/trail/clean/fade) · arcW · checkW · S per-theme. Хвіст-фраї як растр не векторяться — **файл-лаунчер = PNG Konst-а**, у хедері вектор-спрощення (dissolve/taper).
- **Accent = A45 per-theme**: окремі S/L для light і dark (на темній S/L заливки = головний важіль проти неону/washed; на світлій токен багатий). Hue тримати **далі від ~176–182** (Lens Slate-Teal #2A8C84 = колізія).
- Tile-параметри рекомендація: **розмір 34 · радіус 10 · inset 5** (44px кнопка, сквіркл ≈0.29×).

**Мережевий фільтр UI**
- Бейдж у кнопці **підтверджує** вибір (не вчить — щойно обрав); повна ідентифікація в дропдауні (бейдж+текст).
- Бейджі = **іконка/бейдж-проксі** (не повний lockup) + уніфікований тайл + **монограма-фолбек** для wordmark-only мереж (напр. Подорожник має плюс+листок; фолбек = загальний запобіжник). Офіційні SVG підтягуються пізніше (пісочниця не пускає сайти мереж — стендіни інлайн-SVG).
- **«Усі мережі»** = без фільтра по `net`, плоский список. Бейдж мережі на картці показується ТІЛЬКИ в режимі «Усі». Глиф «Усі» у великій кнопці/дропдауні = **2×2 сітка** (◍ відкинуто — погана на великій кнопці). Категорійний чип «◍ Усі» (OTC-фільтр) — інша система, лишається.
- Дропдаун: пошук з'являється **умовно при N>~8**.

**Хедер — тип** (тумблер у бенчі: острівний ⇄ прикріплений)
- Острівний = плавуча картка. **DEFERRED**: зараз читається як «два шматки фону трохи вище» — бракує матеріальності. Якщо острівець — має **плавати** (сильніша елевація + напівпрозорість/блюр + окрема поверхня). Sticky-on-scroll → backdrop ≤12px (cookbook). Розберемось пізніше.

**Девайс-фрейми (канон-числа)**: XS 375×812 (SA 44/34) · 15 Pro 393×852 (Island 59/34).
