по брендах

## 1. Контекст і задача

На роботі впроваджено новий обов'язковий Excel-файл
`Фармастор_замовлення_тт.xlsx`.\
СР при кожному польовому візиті до аптеки мережі **Фармастор**
заповнюють фактичні залишки товарів на полиці. Excel рахує замовлення по
формулах (MSL − Залишок). Файл незручний з телефону.\
**Ціль:** мобільний single-file HTML-інструмент із збереженням між
сеансами та XLSX-експортом для керівника.

## 2. Дослідження Excel-файлу

### Структура (3 листи)

  Лист         Рядки   Опис
  ------------ ------- --------------------------------------
  **АП**       5 229   63 аптеки × 83 SKU --- повна матриця
  **MSL**      83      Нормативи A/B/C/D для OTC і IW
  **Sheet1**   0       Порожній, технічний

### Колонки АП (15 --- незмінна структура)

    Proxima Pharmacy ID | Area | City | Outlet Address | Network |
    Category OTC | Category IW | Custom.SKY | Custom.Category |
    Custom.Kode | Custom.Price | Кількіть MSL | Залишок | Замовлення | Column1

### Логіка формул (оригінал)

-   `Замовлення = Кількіть MSL − Залишок` (може бути від'ємним)
-   Якщо Залишок порожній → Excel трактує як 0 → `Замовлення = MSL`
-   `Column1 = Замовлення × Custom.Price`
-   **Наш HTML** використовує `MAX(0, MSL − Залишок)` --- не показує
    від'ємних

### Оригінальний стиль таблиці

-   Тип: Excel Table `TableStyleMedium7` на обох листах (АП і MSL)
-   Theme Accent 1: `#156082` (темний тіл/синій)
-   Theme Accent 2: `#E97132` (помаранчевий → використано для Залишок)
-   showRowStripes: true --- почергові смуги рядків

## 4. Архітектура

### Single-file HTML (\~468 KB)

-   Вся логіка, стилі, дані, бібліотека --- один `.html` файл
-   Не потребує сервера, інтернету, встановлення

### Вбудовані дані (JSON-константи)

``` javascript
const PH = [ /* 63 аптеки */ ];
const MSL = [ /* 83 SKU */ ];
```

### State schema (localStorage key: `farmstore_v1`)

``` json
{
  "date": "2026-07-10",
  "phs": {
    "121825": { "3042192": 1, "312947": 0 },
    "155921": { "3042192": 3 }
  }
}
```

-   Ключ: Pharmacy ID → SKU kode → значення Залишку (число)
-   Відсутній ключ SKU = не введено (≠ нулю)
-   `0` = явно введений нуль (все продано)

### 3-екранна навігація

    Home → Select Pharmacy → Fill SKUs → Home
             (місто → аптека)  (бренди accordion)

## 5. Fill Screen --- Brand Accordion

### Групування SKU по брендах

  Категорія   Бренд               SKU
  ----------- ------------------- --------
  OTC         Стрепсілс           11
  OTC         Нурофен             20
  OTC         Гавіскон            7
  IW          Durex               31
  IW          Contex              10
  IW          Evitest / Eviplan   4
  **Разом**                       **83**

### Логіка accordion

-   При відкритті аптеки --- всі бренди **розгорнуті** (якщо ще не
    заповнені)
-   Якщо бренд вже повністю заповнений при відкритті --- **одразу
    згорнутий** зі статусом `✓ готово`
-   Після заповнення останнього SKU бренду → **авто-згортання** +
    зелений статус
-   Тап на заголовок бренду → розгорнути/згорнути вручну
-   `openBrands` --- об'єкт стану accordion, скидається при кожному
    відкритті аптеки

### Детекція бренду (функція `getBrand`)

``` javascript
/^(Стрепсілс|СТРЕПСІЛС)/i → 'Стрепсілс'
/^Нурофен/i               → 'Нурофен'
/^Гавіскон/i              → 'Гавіскон'
/^(Durex|Гель Durex)/i    → 'Durex'
/^Contex/i                → 'Contex'
/^(Evitest|Eviplan)/i     → 'Evitest / Eviplan'
```

## 8. Технічні примітки

-   `<meta name="color-scheme" content="light">` --- блокує темну тему
    iOS/Android
-   Пісочниця Claude показує темний фон --- це артефакт, реальний вигляд
    світлий
-   `TOTAL = MSL.length` (83) --- хардкод прогрес-бару, оновлюється
    автоматично при зміні MSL
-   localStorage ключ `farmstore_v1` --- при зміні схеми стейту →
    змінити версію ключа
-   `font-size:16px` на input → блокує автозум iOS при фокусі
-   `inputmode="numeric"` → цифрова клавіатура на мобільному
-   `openBrands` не зберігається в localStorage --- це UX-стан, не дані
