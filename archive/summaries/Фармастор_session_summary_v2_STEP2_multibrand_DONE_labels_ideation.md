## 3. ІДЕАЦІЯ Home/пікер/історія — рішення для наступної фази (design + logic)

### 3.1 IA — ЛІН (без повного tab-bar) ✅
Фармастор = задачний (зайшов у точку → полічив → вставив → вийшов), не browse-застосунок. Повний bottom-tab = зайвий chrome. **Рекомендація:** Home (маршрут) → drill у FILL → назад; About / CSV / очистити-сеанс — у хедер-меню (•••). Менше — краще. (Konst згоден.)

### 3.2 🔑 NORM-RESOLVER — найважливіша невирішена логіка (Konst: критично)
- **Категоризація SKU:** `OTC` = Стрепсілс·Нурофен·Гавіскон; `IW` = Durex·Contex·Evitest. (MSL має колонку `Category` = OTC/IW — використати її, не хардкодити бренди.)
- **Норма tier-resolved:** кожна аптека має ДВА тіри (`oTC` + `iW`, A/B/C/D). Норма SKU = колонка MSL, обрана тіром за категорією: OTC-SKU → `pharmacy.oTC`; IW-SKU → `pharmacy.iW`. MSL має 4 колонки норм `A|B|C|D`.
- Наслідок: ghost-норма + δ-чіп **різні для кожної аптеки**. Harness показував A плоско — прод мусить резолвити per-SKU. Це має лягти в порт (norm-resolver: `SKU.category → pharmacy[tierKey] → MSL[column]`).
- Наслідок для UI: картка аптеки несе профіль тіру `OTC B · IW C` (він визначає всю сітку норм).

### 3.3 Пікер аптек — знести нативні `<select>`
Поточне (слабке, device-підтверджено): каскадні нативні селекти; адреси переносяться посеред слова («Гетьман-ська»); тіри в дужках `[OTC:B IW:C]`; алфавітний скрол 14+ міст; без пошуку по 63 аптеках.
**Редизайн:**
- **пошук-перш**: одне поле (назва / адреса / Proxima `id`) з живим фільтром;
- аптеки **згруповані по місту зі sticky-заголовками** (реюз FILL-акордеон-патерну);
- рядок: `addr` сильний (ellipsis, не перенос) · `city`/`net` тихо · тір = **два чисті міні-чіпи** `OTC A`/`IW C` (не дужки) · Proxima `id` дрібним muted (унікальний розрізнювач, sort-robust);
- **недавні / закріплені** зверху (представник вертається в ті самі точки);
- відкрите: тап-по-аптеці → одразу FILL, чи крок-підтвердження з прев'ю якоря `M{X}`? (вирішити наживо).

### 3.4 Home / «Мій маршрут» — редизайн
- **3 стани картки аптеки:** `не почато (0/83)` · `заповнено X/83 → 📋 готове до переносу` · `перенесено ✓✓` (заспокоєна/пригашена). Активні спливають вгору, перенесені тонуть/згортаються.
- **Прогрес** візуально (ринг/бар X/83), не лише текст.
- **Два прапорці** (STEP1 §7): `filled` ≠ `transferred`. Тихий nudge «не перенесено» на заповнених-але-не-скопійованих.
- **Дуальний якір на картці:** `→ M{X} · Proxima {id}` + `[📋 Копіювати]` (copy-контракт).
- «Очистити сеанс» — прибрати з-під ока (зараз великий рожевий конкурує) → хедер-меню + гард-підтвердження.

### 3.5 §7 EXPORT — перегляд моделі ✅
Прибрати bulk-«Експорт XLSX (N аптек)» + бібліотеку `xlsx-js-style` (−425 КБ). Реальний воркфлоу = **per-аптека копі-контракт**: 📋 копіює 83 значення однієї аптеки (master-order, by-kode, пропуск=порожній рядок) → вставляєш у клітинку `M{X}` майстра. ### 3.6 ІСТОРІЯ ЗАЛИШКІВ — нова фіча (Konst: «крута тема»)
Датовані знімки по аптеці (STEP1 §8 per-аптека date вже є). Інтерпретація:
