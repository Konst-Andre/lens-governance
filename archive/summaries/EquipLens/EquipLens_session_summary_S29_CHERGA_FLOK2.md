## §2 · ДЕФЕКТ, ЯКИЙ ЦЯ СЕСІЯ ЗНАЙШЛА

**`v17_15` не робив того, що було оголошено.** Оператор просив запекти вироки в дефолти.
Зроблено було інше: засів реєстру `LOCKS` + кнопка `RESTORE LOCKS`. Механізм:

```js
if (Object.keys(LOCKS).length || LOCK_STALE.length) return false;   // ← р.1683
Object.keys(LOCK_SEED).forEach(k => { … S[k] = LOCK_SEED[k]; });
```

Засів писав у `S`, **але тільки при порожньому сховищі**. На будь-якому пристрої, де стенд
уже відкривали, `localStorage` непорожній → `return false` → стенд відкривався **заводським**,
а 196 вироків лежали в білді невидимими.

**Клас помилки — той самий, що `З-30`/`Г-9`:** механізм живий за оголошенням, мертвий за
середовищем. Ловиться не грепом, а рукою оператора: «дивлячись по цифрам, ти нічого не зробив».

**Фікс** (`v17_16`, р.1664, **після** знімка `S0`): запікання безумовне й окреме від засіву.
Заводська гілка не втрачена — «ставка» далі вертає `S0`. Числа не дубльовані: `LOCK_SEED`
лишається єдиним носієм, `S` бере з нього.

⚠ **Наслідок, який треба знати:** на пристрої зі **старим** сховищем реєстр покаже drift.
Це чесна різниця, не баг. **`RESTORE LOCKS` там не тиснути** — відкотить у старе.

## §4 · СПЕКА `К22-в` — план пройдено, код не починався

**Ріжеться на два кроки предметом (В-14):**

**Крок 1 · `glift`** — головний носій об'єму, лікує причини А+Б (`S28 §3`). Три важелі:

```
cdGliftD   0…24    приріст L верхньої зупинки над тілом (пункти L)
cdGliftAD  0…40    альфа шару, %   ← вимикач: 0 → --cdGlift:none
cdGliftHD  20…100  висота згасання, %
```
```
--cdGlift: linear-gradient(180deg,
    hsla(dkH, dkC*0.92, dkL+dkS+cdGliftD, cdGliftAD/100) 0%,
    hsla(dkH, dkC*0.92, dkL+dkS+cdGliftD, 0)            cdGliftHD%)
```
Носій — `background-image` на `.el-item`, **окремою властивістю після** `background:`
(шорткат р.433 скидає `background-image`). Світла: `--cdGlift:none` завжди.

**Чому три важелі, а не два зі спеки `S28`.** Якщо альфу взяти з тіла (`cdAD/100`), то при
`cdGliftD=0` верхня зупинка = колір тіла при альфі тіла → композит `0.375+0.375×0.625≈0.61`.
Нуль важеля перестає бути нейтральним: перший клік — стрибок, решта — дрібні прирости.
Замір такого важеля недійсний (клас `З-61`). Незалежна альфа тримає нуль чесним.

**Перед раундом — коду не треба:** `cdBevTD 5→0`, `cdBevSD 3→0` руками. Тоді `glift`
судиться проти **одного** силуету, а не проти подвійного контуру (`14.14`).

**Крок 2 · направлений силует:** `cdRimTD/cdRimSD/cdRimBD` **замість** `cdRimAD`
(усі три дефолт `26` — `1.18`, картинка не рушить) + `cdRimWD` (роздільна товщина по темах,
`A95`: коефіцієнт не працює, потрібні два важелі). `.el-sw` дістає `border-*-color` по сторонах;
на світлій усі три резолвляться в те саме `hexA(cdInk, cdRimAL/100)` → **світла не рухається**.

**Звірка з каноном (`Д-7`):** `A45` (MANIFEST: `glift` — базовий DARK-важіль, білий-інжект
**заборонено**) · `A102` (на прозорому тілі шейдинг читається «всередині матеріалу» — це і є
«картка сяяла») · `A99` (прямокутник → лінійний градієнт) · `A95` · `A101-б`.

⚠ **Друга зупинка — `hsla(…,0)`, ніколи `transparent`:** `transparent`=`rgba(0,0,0,0)`,
sRGB-інтерполяція тягне середину в сірий.
⚠ **Що зробить замір недійсним:** живий `cdBlur=12` підмішує аврору під картку (`A100`).
Ставка — перший раунд при `cdBlur=0`.
