## §3 · ВИРОКИ СЕСІЇ

| | |
|---|---|
| **В-14** | **Важіль атомарний: розмітка + `slider()` + рядок у `conds()` — це один крок, а не три.** Розмітка `.bx-lv` без реєстрації ламає смоук («кожен рядок має замок»), тобто «HTML перед JS» у чистому вигляді дало б файл із червоним гейтом заради формального дотримання порядку. Порядок обслуговує гейт, а не навпаки. *(Підстава: `К9'-1` планувався з повзунком, повзунок свідомо перенесений у `К9'-2`.)* |
| **В-15** | **Лок, який сам оголосив питання відкритим, не є забороною.** `MASTER_LOCK §10` тримає і «прив'язку до бренд-гами» (залочено, без підстави), і «конкретні значення токенів — відкрито, девайс арбітр». Читати перше як заборону на друге — помилка читання, не порушення канону. Дзеркало §17: там залоченим виявилось те, що вважали загубленим. |
| **В-16** | **Веб-перевірка міняє патч, а не підтверджує його.** Пошук по `color-mix` не «підтвердив, що все гаразд» — він зняв механізм із патча до того, як той поїхав на девайс. Тригер перевірки: властивість, чий дефект **не видно оком на цільовій темі**. |
