## 1. ЗАБЛОКОВАНО цієї сесії (harness v1→v3, device-viewed)

### 1.1 sr-pill ім'я → «Прізвище В.» (display-only)
- **Рішення:** пілюля показує скорочене `fmtSrName(nm)` = «Прізвище І.» (2 токени → прізвище + ініціал імені + «.»). Повне ФІО лишається у дропдауні/шіті вибору SR.
- **Логіка:** `function fmtSrName(nm){const p=String(nm).trim().split(/\s+/);return p.length>1?p[0]+' '+p[1].charAt(0)+'.':nm;}`
- **Причина перемоги:** єдиний варіант, що ГАРАНТОВАНО влазить на будь-якому імені (навіть найдовше «Константінов Андрій»), проф. UA-регістр, консистентно. Варіант G (повне без аватара) — тендітний по ширині на довгих іменах при наявному вордмарку.

### 1.2 ЕКСПОРТ БЕЗПЕЧНИЙ — верифіковано (grep + VBA), НЕ з памʼяті
- Джерело імені: `renderHeader` → `nm = sr().n = DATA[S.sr].n` (повне). Споживачі: пілюля `srNm` (тручиться), аватар `srAv=nm.charAt(0)`, дропдаун `.sr-opt-name=${d.n}` (повне лишається).
- Розпакував `vbaProject.bin`: VBA будує JSON із Excel-таблиць (`_SR_List`/`_QR_Data`/`DataBodyRange`/`ReadLOData` → `---- SR entry ----` → `{"n":"…"}`) і вставляє в `/*__DATA__*/`. Потік **односторонній**: Excel→VBA пише DATA→HTML читає DATA. VBA ніколи не читає DOM.
- **Вердикт:** `fmtSrName()` сидить downstream від DATA (читає, не пише) → скоротити пілюлю **фізично неможливо зламати експорт**. Занепокоєння Konst закрите.

### 1.3 sr-pill аватар → трек «СІБЛІНГ»
- **Рішення:** аватар = **той самий матеріал-рецепт, що й `qr-tile`** (accent-15% tint fill + та сама елевація), ініціал у `--accent-text`. Диференціація від плитки: форма (коло vs squircle r9) + вміст (літера vs QR) + вордмарк між ними.
- **CSS-старт (harness v3, ще НЕ в базі):**
  ```css
  .avatar.t-sib{background:color-mix(in srgb,var(--accent) 15%,var(--card));color:var(--accent-text);box-shadow:0 2.5px 5px -1px rgba(0,0,0,.22)}
  [data-theme="dark"] .avatar.t-sib{box-shadow:inset 0 1px 0 rgba(255,255,255,.158),inset 0 -1px 0 rgba(0,0,0,.22)}
  ```
- **Принцип-урок:** аватар не має ПЕРЕКРИКУВАТИ плитку (ієрархія бренд→аватар). Сіблінг вирішує конкуренцію **когезією, не гучністю**.

### 1.4 Відхилено (з причинами — не воскрешати без нових аргументів)
- **Per-SR колір** — проти стриманого teal-характеру проєкту; ідентичність-через-колір ніхто не кастомізує/не вивчає; same-initial репи (Дяченко/Дуднік) колір розрізнив би, але цінності мало. Паркінг.
- **Матеріал-яскравий** — на dark аватар яскравіший за плитку → інверсія ієрархії.
- **Тихий (нейтр. well)** — на dark провалюється в bg; рятувати лише обводкою (тихий+обвід комбо) = марна складність, коли Сіблінг закриває чистіше.
- **Обвід / Плаский** — обвід легкий але порожнє тіло; плаский = поточний, найгучніший.
