## 1 · ЩО ЗРОБЛЕНО (v4 → v4_3)

### 1.1 Верхівка — ЄДИНЕ полотно (уніфікація) ✓ LOCK
- Стара «розірваність» (вердикт=біла картка + band+фільтр «безпритульні» на фоні → світлотемна «чорнота» жолобів) — **прибрана**.
- Тепер **1 картка `.sumcard`, 3 інтегровані зони:** `[статус + tally]` · тонкий дільник · `[фільтр-тунель]`. Нічого не висить на фоні (намір Konst).
- Фікс «чорноти»: `.scroll{background:var(--bg)}` явний + `<meta name="color-scheme">` + `:root/[dark]{color-scheme}`.

### 1.2 Композиція A vs B — **A = робочий напрям**
- **B** = дата вертикальний стовп-пігулка справа (плитки в ~65% ширини).
- **A** = дата горизонтальна пігулка згори-праворуч, **3 плитки на всю ширину** + нижча картка.
- Усі рішення сесії (матеріал, caption, стан) знято В **A**. B **не відкинуто формально** — на початку порту підтвердити «A фінал» одним рядком. Обидва лишаються тумблером у harness (`Верхівка B/A`).

### 1.3 Dark-tile матеріал ✓ LOCK (device-tuned Konst)
- **Баг, який фіксили:** на темній я застосував світлий підхід — заливка `surface-3` майже не світліша за картку + ридж `inset .06` невидимий → плитки пласкі.
- **Правильно (A45/A66.1):** темна = **tone-lift** (плитка помітно СВІТЛІША за картку) + видимий верхній ридж + нижня темна грань; **drop=0** (OLED-мертвий).
- **Залочені значення (bench, device✓):** `Dlift=10 · Dridge=16 · Dgrane=12 · Dbord=7`.
  - Dlift = біле% у surface-3 (тон-lift). Dridge = верхній світловий ридж ×.01α. Dgrane = нижня темна грань ×.01α. Dbord = підсвітка рамки біле%.
- **Світлі плитки:** drop blur **16px** (A66: <14px читається як «потемнів край», не lift). Заливка = легкий верт.градієнт + hairline.
- Плитки **ПІДНЯТІ** — свідомо відрізняються від інсет-**well** рядків (well=recess=поле вводу; tile=lift=summary).

### 1.4 KPI-контекст (tally «до чого відносно») ✓ LOCK
- Проблема: tally не казав, ВІДНОСНО ЧОГО «ближче/далі» → це MSL-норма.
- **Рішення (моя ставка, device✓ «доречно»):** **whisper-caption «відносно MSL» ПІД словом-статусом** — сидить у наявних 34px висоти іконки-статусу → **компонент НЕ виріс** (0 доданої висоти). Caption контекстуалізує і вердикт, і всі 3 плитки.
- **Підписи плиток = «до норми / від норми / без змін»** — **вибір Konst** (проти мого ліну «ближче/далі»; «по-людськи зрозуміліше»). Зв'язка залочена: **caption ON + до/від норми**.
- Відкинуто: first-run hint (ефемерний). Tooltip ⓘ — опційний вторинний на майбутнє. Іконки — лишити.

### 1.5 Стан-вердикт (3 стани) ✓ device✓ обидві теми
- `up=Покращилось` (тренд-вгору SVG, accent) · `down=Погіршилось` (тренд-вниз SVG, warn) · `flat=Без змін` (=, muted). Іконка в м'якому кольоровому кружку (світла: 13% mix; темна: 22% у surface-3). Видно нормально.

### 1.6 Малі фікси (застосовані у v4_3)
- **mode-a:** «Покращилось» майже торкалось date-pill → `gap 12` + `st-head min-width:0` + date-pill стиснутий (`18.06–02.07` без пробілів). Перевірити на XS ще раз.
- **MAT** у файлі синхронізовано до locked `10/16/12/7` (був stale 9/14/20/6).
