### 1.2 Модель РЕАЛЬНИХ назв (ключове відкриття — джерело §2 `Farmastor_multibrand_harness_v1.html`)
Назва рядка = **коротка `v` (БЕЗ бренду — бренд у заголовку акордеона)** + чіп-фасовка `pk` інлайн + `fd` (дрібний дескриптор форми, напр. «таб. 400 мг») + MSL знизу.
- Стара mock-фікстура мала ПОВНІ назви («Стрепсілс Інтенсив спрей, фл.15мл») → штучно тиснуло. **Виправлено** — фікстура v6 з реальними короткими назвами.
- Edge-кейси в фікстурі: cross-norm (Нурофен Експрес Форте, MSL 4→3 = WARN), absent-нов./вилуч. («—»), **порожня `v`** (Нурофен «таб. 200 мг» — назву несуть fd+pk), t=0 crit.
- rowHTML: `nameMain = it.n || it.fd`; fd як tiny-suffix якщо є обидва; чіп `pk` лише якщо непорожній.

### 1.3 colhead-«ДІМ» (борг HIGH-3 закрито в дизайні)
- Власна **поверхня-підложка** під шапкою дат+зміни. **Full-scope = ДЕФОЛТ** (Konst: «краще на всю ширину»). Опція `cols` (дах лише над колонками) лишена.
- **Manifest per-тема (canon_delta_A45_material_lever_manifest):**
  - LIGHT: tint (`Lbg`→bg-soft) + border (`Lbord`) + drop (`Ldrop`).
  - DARK: tone-lift (`Dbg` біле%→surface-3) + ridge (`DridgeC`) + dip (`Ddip`) + border (`DbordC`), **drop=0, без white-inject.**
  - Змінні дому DARK назвали `DbordC/DridgeC` — НЕ плутати з tile-важелями `Dbord/Dridge` (верхівка).
- **Ліва підказка = «SKU»** (навпроти назв продукту), вертикально вирівняна з датами (прибрано зсув угору, розмір 11px матч).
- **Перший eyebrow під домом — `border-top:none`** (`.bbody>.ebrow:first-child`) — прибрано колізію «дім + лінія». Дільники між суб-групами лишились.

### 1.4 Δ-колір у «ЗМІНА» — ПІДТВЕРДЖЕНО §5.1, БЕЗ ЗМІН
- Колір = **дистанція до норми, НЕ напрям**. `moveLevel()`: `|t−MSL|` vs `|f−MSL|` → ближче=accent/зелений, далі=warn/помаранч., 0/зникло=crit.
- Знак (+/−) = сира магнітуда/напрям окремо (§5.1 «видиме сире число»). Приклади: «7→4 −3» зелений (перебір→ближче до норми); «5→11 +6» помаранч. (приріст→далі від норми).
- Konst спарканував логіку. Реопен §5.1 ЛИШЕ якщо на девайсі sign/color-decoupling читається плутано.

### 1.5 Панель харнеса — виправлено перекриття стейджу (wsd 2.4a)
- Була переросла екран (grip виїхав, скрол «зламався»). Тепер: **`max-height:52dvh` + flex-column + внутрішній скрол `.pbody` + закріплений grip**. Прибрані зайві ряди (Верхівка/Контекст/Стан/Підписи/Плитки/Плитки☾) — лишені лише дім-релевантні.

## 2. ВІДКРИТІ БАГИ / ХВОСТИ (порядок для нового чату)

### 2.1 [BUG · пріоритет 1] Sticky-дім НЕ ПІНИТЬСЯ (device: iPhone, iOS 18/26)
- Konst підтвердив: `sticky on` → дім **взагалі не пінится** (не тільки per-brand-зникнення — не пінится взагалі).
- **+ Артефакт Нурофена:** при `sticky on` над карткою Нурофена **піднімається порожнє поле** (лише на брендах із суб-групами/ebrow; на flat-брендах нема).
- **Провідна гіпотеза:** iOS-quirk `position:sticky` всередині `.scroll{flex:1;overflow-y:auto}` — висота скрол-рута похідна від flex, не явна. + стек `[data-chsticky=on] .ebrow{top:calc(var(--chH)+10px)}` ламає ebrow-sticky (він у `.bbody{overflow:hidden}`).
- **Кандидати-фікси (перевірити на девайсі):** (a) явна висота скрол-рута (`height:100dvh` мінус header, або `min-height:0` по flex-ланцюгу); (b) прибрати/переробити ebrow-offset; (c) винести дім у структуру, що НЕ trap-иться; (d) розглянути **глобальний** дім (один зверху #list) замість per-brand — Konst відкритий до цього варіанту.
- Грепати live-code перед фіксом (wsd 12.1). Sticky-CSS зараз: `[data-chsticky="on"] .colhead{position:sticky;top:0;z-index:6;background:var(--cardBg)}`.

### 2.2 [FEAT] Бракує важелів per-осях для тексту шапки «SKU · дати · ЗМІНА»
- Konst хоче контролювати **кожну вісь окремо**: позицію/розмір «SKU» (left-pad, size), вирівнювання дат-колонок, акцент «ЗМІНА».
- Додати в харнес групу важелів: `skuPad`, `skuSize`, `hcAlign` (баланс дата-колонок), `chgEmph` (вага/колір ЗМІНА), верт-вирівнювання лейблів.

### 2.3 [LOCK-pending] Матеріал дому НЕ device-locked
- Важелі є (Дім☀ Lbg/Lbord/Ldrop · Дім☾ Dbg/DbordC/DridgeC/Ddip · геом chH/chRad), але copyValues Konst ЩЕ не передав. Треба: затюнити світлу+темну ОКРЕМО на девайсі → зафіксувати copy-рядок → лок.
