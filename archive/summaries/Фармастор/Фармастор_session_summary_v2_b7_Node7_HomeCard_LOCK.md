## Залочені рішення (канон → §5.2/§6.4)
- **Композиція:** 2 колонки `[ідентичність 1fr | кільце-герой auto]` + футер на всю ширину. Вбиває стару L-порожнечу.
- **Кільце-статус поверх 3-станової §5:** порожнє сіре+«—» (не почато, БЕЗ слова) · partial-hue дуга «X/83 + %» (готове ≥1) · full-hue повна «100%» (повне 83) · dim+✓✓ (перенесено).
- **Режим «дуга»:** % у розриві кільця (rotate 135°, pathLength=100, gap 90° знизу).
- **Копі-слово = `%`** (54%/100%), НЕ «готове/повне» (дедуп: «готове» дублювалось = обман; % чесніше+магнітуда).
- **число-герой збережено** — число всередині кільця герой, кільце = статус-рамка+прогрес.
- **Двоколірний fill (hue за станом):** partial бірюзовіший / full зеленіший (teal→green мокапа через hue).
- **Тір = тінт inline-рядок** `OTC B · IW C` (порівняно проти чіпів/нейтралу → тінт обрано), per-тема.
- **«не почато» = «—» без слова** (Konst-lock: порожнеча чесно = «не зроблено»; «0%» заборонено — не поміряно≠нуль).
- Рейки нема (§3.3). Динаміка-афорданс visits≥2→«Динаміка ›» / 1→«показники ›».
