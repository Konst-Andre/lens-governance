## 2 · ЗАФІКСОВАНІ РІШЕННЯ (harness-locked, нести в v4-порт)

**Row-анатомія = ГІБРИД:** `[назва / pack-чіп / MSL-підрядок]` · `[було-well][стало-well]` · `[Δ-герой]`
- **було** = приглушене (minule), 14px/700 muted · **стало** = суцільне (поточне), 16px/800 · нейтральний інсет-well обидва.
- **Δ-герой = T2 «гніздо»** (обрано Konst): власне гніздо, тоноване `--sig` рівнем, **ПІДНЯТЕ** (не інсет) — щоб око відділяло «різницю» від «залишків».
  - Світла: `fill sig 14%` + `border sig 44%` + топ-глянець `inset .55` + drop `sig 20%`.
  - Темна (A66.1 tone-lift): `fill sig 24% surface-3` + `border sig 50%` + **top-ridge emboss `inset .20`** + нижня грань `inset -.22` + drop `.22`. *(v3-покращення; device-verify фінально в порті.)*
  - lv-none (still/na): нейтральний surface-2/3, без кольору.
- **T1 чіп+ / T3 голе** — відкинуто (T2 обрано), але лишались у harness як компер.

**Δ-колір (moveLevel) = ДИСТАНЦІЯ-до-норми, НЕ напрям:**
- `dF=|f−nF|, dT=|t−nT|` → `dT<dF`=closer(lv-ok/accent) · `dT>dF`=farther(lv-low/warn), а `t===0`→crit · `f===t`=still(muted) · absent будь-де=na(«—»).
- **Cross-norm edge (був вище→провалився нижче, дистанція рівна) = WARN** ✓ locked.
- Сире знакове число `+N/−N` завжди видиме (напрям несе знак, не колір).

**Статус-фільтр = сегмент `Усі / Змінилось / Проблемні`** (persist thumb, A54):
- **Змінилось** = будь-яка зміна в обидва боки (прихід `+` / продажі `−` + поява/зникнення); ховає лише `still`. *(«Рух» перейменовано — вантажене, читалось як «лише продажі».)*
- **Проблемні = ПОТОЧНИЙ СТАН `t < норма`** (недостача ЗАРАЗ = список на дозамовлення), **НЕ за рухом**. *(Виправлено ваду: SKU, що покращився до норми, виходить з «Проблемних»; що покращився але <норми — лишається. Рух і стан — різні питання. Заодно вирішує overstock: `t>норма` НЕ проблема.)*

**Вердикт-шапка** = tally за РУХОМ: `↑N ближче до норми · ↓N далі · =N без змін` + слово (покращилось/погіршилось/без змін). Стрілки **ЛИШЕ у вердикті** — біля гнізд стрілок НЕ додавати (Δ-знак уже несе напрям; дублювання акценту — відкинуто).

**Підписи колонок = ДАТИ** (`18.06 / 02.07`), 11px · Δ-колонка = слово **«ЗМІНА»** (гліф Δ не всім ясний).

**absent-чесність:** present→absent → стало «—», Δ **порожній** (без дубль-«—») · absent→present → «новий» бейдж (dark-safe: `accent 26%`, НЕ accent-soft) АБО порожньо (`newmode`, фінал не лочено — Konst тестив dash; схил до «новий»).

**Структура:** Нурофен = ОДНА картка бренду + вкладені sub-group eyebrow (реюз FILL). Лічильник бренду = N видимих (не «X/Y» — плутанина з FILL X/83).

**Плюмбінг у базі вже є** (реюз, не писати): `normOfVisit(vis,ph,s)` (р.1240) · `normFor(k,tier)` (р.828) · `MSL_BY_K` · класи `.cat-div/.brand/.bhdr/.bwrap/.ebrow/.eb/.rows/.row/.dchip/.lv-*`.

## 5 · УРОКИ
- **Harness-first виправдав себе:** 3 device-раунди відшліфували анатомію ДО дотику до продукту (нуль ризику для b12.3).
- **Persist-DOM + thumb (A54) для сегмента:** ре-рендерити ЛИШЕ список, сегмент лишається → тап надійний + анімація безкоштовна. Ре-bind per-render — крихко на iOS.
- **Розділяти СТАН від РУХУ:** «Проблемні» = стан (`t<норма` зараз), Δ-колір = рух (дистанція між візитами). Не плутати — відповідають на різні питання; плутанина = вада фільтра (Konst спіймав).
- **Реальні дані у фікстурах критичні:** довгі реальні назви ≠ mock — інакше не оцінити лейаут (Konst спіймав вигадані назви).
- **Світлотемна «чорнота» = структурна, не колірна:** елементи на різних поверхнях (біла картка vs фон сторінки) читаються як різні рівні → уніфікувати. Греп dark-значень (чистий) виключив колір-витік.
- **Δ-матеріал ≠ матеріал залишку:** кольорове+підняте (Δ) vs нейтральне-інсет (залишок) — око розділяє «різницю» від «даних».
