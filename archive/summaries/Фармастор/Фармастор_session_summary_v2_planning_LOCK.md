## 0. Що це за продукт (одним абзацом)

Мобільний single-file HTML/PWA-інструмент для СР: **комфортно зрізати залишки** (кількість на полиці) по кожному SKU під час візиту до аптеки мережі Фармастор, а потім **перенести числа в корпоративний онлайн-майстер Excel**. Інструмент — зручний фронт-енд для вводу; майстер лишається обов'язковим місцем призначення даних.

## 1. ВЕРДИКТ (чи варте воно того)

## 2. ФАКТИ З ФАЙЛУ-МАЙСТРА (перевірено програмно)

Файл: `Фармастор_замовлення_тт.xlsx`
- Лист **АП**: `A1:O5230` — хедер + 5229 рядків = **63 аптеки × 83 SKU**.
- Блоки аптек **йдуть підряд (contiguous)**, рівно 83 рядки кожен, **порядок SKU байт-у-байт однаковий у всіх 63 аптеках** (старт: Стрепсілс Інтенсив, kode 3042192).
- Колонки АП (15): `Proxima Pharmacy ID | Area | City | Outlet Address | Network | Category OTC | Category IW | Custom.SKY | Custom.Category | Custom.Kode | Custom.Price | Кількіть MSL | Залишок(M) | Замовлення(N=формула) | Column1(O=формула)`.
- **Представник заповнює ЛИШЕ колонку M (Залишок).** N і O — формули, самі перераховуються.
- Лист **MSL**: `SKY | Category | A | B | C | D | Kode | Price` (83 рядки). **MSL різний по категорії** (напр. kode 3020906: A=8/B=6/C=4/D=2). Аптека має ОКРЕМІ категорії OTC та IW → для OTC-SKU береться OTC-категорія аптеки, для IW-SKU — IW-категорія.
- **Порядок PH у HTML == порядок у файлі** (перевірено) → адреса клітинки вираховувана.
- MSL-по-категорії в поточному HTML **коректний** (Підгородне OTC:B → показані MSL збігаються з колонкою B). Не баг; берегти при оновленні даних.

## 3. АРХІТЕКТУРНИЙ ЗСУВ (ядро змін)

**Стара модель:** заповнив усе → експорт одного стильного `.xlsx` (через `xlsx-js-style`, ~425 КБ бібліотека, ~226 КБ вихід) для керівника.

**Нова модель:** аптека → **копіюй стовпчик Залишку → встав у майстер → наступна.** Per-аптека, не батч.

**ВИДАЛИТИ:**
- `xlsx-js-style` бібліотеку повністю (−425 КБ; файл ~468 КБ → ~40 КБ, миттєве відкриття).
- Стильний `.xlsx` експорт (керівник читає онлайн-майстер, не копію).
- Колонку «→ Замовлення» в рядку SKU (шум для цього тула; майстер рахує сам).

**ЗАЛИШИТИ як другорядну страховку:**
- Легкий **нативний CSV** експорт (~10 рядків, нуль бібліотек). НЕ основний шлях.
- Native share-sheet для CSV лишається як є (це вікно ОС, юзери йому довіряють).

**Основний перенос = буфер обміну:**
- «📋 Копіювати» → 83 значення, по одному в рядок, **у порядку SKU майстра**, **пропуски = порожні рядки** (щоб не затерти чуже нулем).
- **Перевірено Konst на девайсі:** вставка заповнює стовпчик коректно, переживає закриття/відкриття Excel.

## 4. МЕХАНІКА ПЕРЕНОСУ (locked)

- Картка аптеки показує **ОБИДВА якорі:**
  - точну клітинку `M{X}`, де `X = 2 + (індекс−1)×83` (індекс у порядку майстра);
  - **Proxima Pharmacy ID** (унікальний ключ, sort-robust фолбек через Пошук).
- Локація в майстрі: Excel mobile «Home → Виберіть/Перейти до діапазону → `M{X}` **ЛАТИНИЦЕЮ ВЕЛИКИМИ**» АБО Name Box у веб; або Find по Proxima ID.
- **ОБОВ'ЯЗКОВИЙ крок 0: зняти фільтри в майстрі** перед вставкою (вставка у відфільтрований/прихований лист небезпечна). Фільтр ХОВАЄ рядки, але **НЕ переставляє** → `M{X}` лишається чинним після зняття. Ламає `M{X}` тільки **сортування** (→ тоді Find-by-ID). Колеги фільтрують, не сортують → `M{X}`+зняти-фільтр надійно.
- **Мікрокопі нагадування (дефолт):** «Зняв фільтри в майстрі? Тоді встав ↓». Альт: «У майстрі: лійка → Очистити фільтр, тоді встав» / «Фільтри зняті? Встав ↓». Фінал — на девайсі.
- **Статус переносу:** новий per-аптека прапорець `transferred` окремо від `filled`. Home гасить/штампує перенесені («перенесено ✓✓»).
- **Воркфлоу-порада (не код):** переносити ОДРАЗУ після кожної аптеки (в машині), не батчем увечері → мінімальне вікно «дані у двох місцях».

## 5. СТАНИ КОМІРКИ (система повноти — концепт locked, вигляд тюнимо в дизайн-проході)

Три стани, читаються миттєво:
- **не торкався** (ще винен цей SKU);
- **ввів >0** (реальний залишок);
- **ввів явний 0** (перевірив, нема — це ДАНІ, ≠ не торкався).

Рішення:
- **Ghost-плейсхолдер із нормою:** порожнє поле = MSL блідим привидом; ввід замінює на суцільне число → одночасно бачиш норму для звірки І відрізняєш «не торкався» (привид) від «0» (суцільний). Плутанина 0↔порожньо зникає.
- Введений рядок **заспокоюється** (бліднішає/галочка); не введений лишається «активним».
- Бренд-заголовок «14/20» доки не всі; «готово» тільки на повних.
- Кнопка **«↓ наступне незаповнене (N)»** — стрибок фокуса на найближчу дірку (на вимогу). Вбиває полювання очима.
- Опційний чіп **«нема / 0»** біля поля = ствердне «перевірив, нуль» як намір.
- **БЕЗ автопереходу після вводу** (кількість буває багатоцифрова → зарано/смикає). Лишаємо керовані юзером переходи: тулбар «↑ ↓ Готово» (вже є) + «наступне незаповнене». Усі переходи ініціює юзер.

## 6. MSL / ВІЗУАЛІЗАЦІЯ НОРМИ (переграно — це НЕ стан помилки)

- **Овершток (Залишок > MSL) — НОРМАЛЬНО**, не баг. Жодного червоного алярму.
- Візуалізувати «менше/на рівні/більше норми» нейтрально й елегантно: ghost-норма (фаворит) + опційний тонкий інлайн-метр (засічка=норма, заливка=введене).
- Підсвічувати радше **під-норму** (actionable — гонить дозамовлення) м'яко; овершток лишати спокійним. «Приємно бачити», не «мусиш реагувати».

## 7. АКОРДЕОН-АВТОЗАКРИТТЯ (лікуємо різкість, не поведінку)

- Проблема: миттєве зникнення читається як «глюк», доки не побачиш «готово».
- Фікс моушен-тактом: на останньому вводі заголовок бренду програє короткий **«✓ готово» settle** (~500ms glow/галочка), ТОДІ плавно **згортається** (~300ms) — не миттєво. Око встигає прочитати причину. (Твоя A18.1 / settle-glow територія.)
- Згорнутий заголовок тримає «✓ готово · 20/20».
- Якщо все ще спантеличує після моушену → авто-close стає налаштуванням. Але такт має вирішити.

## 8. ПІД-ГРУПИ В АКОРДЕОНІ (Durex, Нурофен)

- Durex (31 SKU) та Нурофен (20 SKU) задовгі плоскими списками. Ділити на **фізичні форм-групи:**
  - Durex: презервативи / гелі;
  - Нурофен: таблетки-капсули / суспензія / супозиторії.
- **НЕ вкладені акордеони** (подвійна глибина тапів задорога для польового тула). Замість: **sticky під-заголовки ВСЕРЕДИНІ розкритого бренду**, не згортаються, кожен із міні-лічильником («Презервативи 8/10 · Гелі 4/6»). Згортається лише БРЕНД. Дає чанкінг + чек-лист-відчуття без зайвої механіки.
- Ціна: другий класифікатор `getSubGroup` за ключовими словами в назвах — для двох найдовших брендів.

## 10. ДИЗАЙН-НАПРЯМ (візуал — тюнимо в харнесі, обидві теми, девайс-арбітр)

**Корінь проблеми:** усе однаково зелене й однакової ваги → «Android-Material шаблон»; важкі обведені картки; емодзі-іконки (🏪 🗑). Lens-сім'я = iOS-native.

Напрям:
- Нейтральні поверхні + ОДИН акцент; зелений тільки семантичний (готово/частково/видалити).
- **iOS inset-grouped списки** (як Налаштування) замість обведених карток.
- **SF-style іконки** замість емодзі.
- Легкий **large-title хедер на світлому**; колір як акцент, не суцільна плита. Нижня «Зберегти» не мусить конкурувати вагою з хедером.
- **Рядок SKU навколо ОДНОГО героя = поле лічби.** Назва (жирна) + форма/обʼєм (тихий 2-й рядок); MSL дрібним чіпом; без «→ результат».
- **Читабельність на сонці** — СР працює в яскравих аптеках: високий контраст, великі тапи. Контекст-специфічно, шаблон цього не бачить.

**Свіжі ідеї (контекстні):**
- Home **«мій маршрут»**: закріплені постійні аптеки зверху (не ходити щоразу місто→аптека).
- Режим **«на сонці»** (високий контраст).
- **Sticky під-заголовок** при скролі довгого бренду.
- **Мікромомент завершення** 83/83 — короткий приємний settle (винагорода рутині).
- **Home-картка переносу**: «→ M168 · Proxima 102520 · [Копіювати]» + нагадування про фільтр → штамп «перенесено ✓✓».
