## УРОКИ ЦІЄЇ СЕСІЇ (generalizable)

1. **Well/inset — найчастіше-губимий матеріал при порті harness→продукт.** 3 елементи за сесію втратили `box-shadow:inset` (лишились плоский bg+border). Плоский порт синтаксично валідний → node не ловить. Гейт: грепати inset/box-shadow сегмент/well-контейнерів проти харнеса. → wsd 10.8.
2. **localStorage = per-origin, НЕ per-file.** Сід-дані не переносяться між контекстами (локальний прев'ю ⇄ деплой). Для device seed-тесту — **вбудовувати сід у тест-білд** (guarded one-shot, свіжий прапорець), не покладатись на персистенцію між білдами.
3. **Мок-сід = окрема `_SEED`-копія**, ніколи не в базі: фейк-аптека в PH (окремий px + підпис) + guarded seed-блок; база лишається чистою для наступного batch. Крафтнуті числа верифікувати прогоном через реальну логіку (`cmpLevel`) ПЕРЕД видачею.
4. **Сегмент-контроли продукту — спільна well-мова.** Усі segment-controls (`.sfilter`/`.thseg`/…) беруть один well-матеріал → консистентність; не тюнити кожен окремо.
