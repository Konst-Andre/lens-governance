## Рішення цієї сесії (DEVICE-PENDING, ще НЕ канон)
1. **Well ☀︎/☾ — окремі методи** (A65/A39, це вже канон, я був порушив у v1):
   світла = inset-shadow; **темна = tone-recess** (поле дипає тоном нижче card до чорного
   `dWellDip` + нижнє світло-рятівник `dWellLight` + м'який inset). Окремі повзунки L/D.
2. **Термін «MSL»** замість «норма» — репу знайоміше. Скрізь у UI (ghost + 2-й рядок).
   → **канон-борг:** оновити крок-1 лок + пам'ять (норма→MSL).
3. **Ієрархія FILL-рядка перебудована** (ключовий інсайт Konst): у акордеоні бренду
   бренд на рядку = шум; реп ідентифікує SKU по **варіант + НОМЕР** (Форте буває №12 і №24;
   капс. №16/№10). Тому:
   - бренд «Нурофен» з рядків **прибрано**;
   - **номер → тег** (`№12`/`капс.№16`/смак) = головний скан-таргет;
   - рядок = `варіант` + `№тег`; 2-й рядок тихий: `таб. 400 мг · MSL 6`.
4. **Сигнал запасу = deltaChip** (обрано проти meter/rail/border/…): чіп `−4`/`+2` = запас vs MSL.
   - **Ідіома A59 «тихо на ок, гучно на недоборі»**: за замовч. світиться лише проблема
     (crit `0` червоний / amber `<MSL`); `≥MSL` мовчить (тогл `showOk` для +тон).
   - Розміщення (тогл, повний контроль): `off/знизу/зліва/справа/кут/у рядок`. **Дефолт «зліва»**
     (знизу Konst не зайшло; зліва — поле лишається на краю для тапу). Насиченість — `chipInt`.
5. **settled-рядок** тогл: `dim-meta` (дефолт — назва читана, гасне лише 2-й рядок) / `tint` / `лише ✓`.
   (v1 гасив усю назву = гірше сканується — виправлено.)

## Що судити на девайсі (XS iOS18 + 15Pro iOS26, обидві теми, «на сонці»)
- Well темної читається як **ямка** (не пласка коробка)? головний важіль `dWellDip`.
- Номер-тег — миттєвий SKU-якір? чи не заважкий на ~20 рядках (може світліший варіант тега).
- Розміщення δ-чіпа: `зліва` vs `кут` vs `у рядок` — що чистіше.
- MSL-режим: `у рядку` (persist) vs `лише ghost` — чи не дублює.
- 3 стани клітинки миттєво читані; явний `0` ≠ порожнє.
- settle-моушен (тригер знизу) + **frame-gap трійка** — `drop` має бути 0 (collapse=max-height, A70).

## Параковані ідеї (💡, на потім)
- **Combo rail + deltaChip** — rail «де недобір» при скані + чіп «на скільки» на фокусі.
- **Ролап у sticky під-заголовок** — «3 недобори» до розкриття групи (ескалація сигналу вгору).
- **graded радіус** — глибший недобір = товща смужка/сильніший тон (ризик шуму).
- `border`/`numTint` форми — ймовірно виліт (border б'ється з well-афордансом; numTint читається як «невалідний ввід»).
